# Navigation·Location 상태와 동작

| 상태 | 동작 | 기대 결과 | 검증 |
| --- | --- | --- | --- |
| 끝점 없음·한쪽·양쪽 연결 | Node 또는 Segment에서 연결·해제 | 양방향 참조와 열거 일치, 상태 변경 후 알림 | NavigationTests, GraphProject |
| 점유·중복·자기 루프 | 연결 요청 | 정해진 예외, 기존 상태 보존 | NavigationTests, GraphProject |
| null·폐기·잘못된 side | 연결·조회 | 입력 또는 수명 예외, 상태 보존 | NavigationTests |
| 여러 구간 연결 | ClearSegments·ClearNodes | 모든 상호 참조 해제, 상대 수명 유지 | NavigationTests, GraphProject |
| 연결된 상태 | Dispose·중복 Dispose | 연결과 Hub 정리, 후속 연결 거부 | NavigationTests, GraphProject |
| 정리 관찰자 실패 | Node.Dispose | 다른 연결도 정리, 예외 전달 | NavigationTests |
| 정방향·역방향 × Length·Rate | Location 환산 | From 기준 거리·비율로 환산 | LocationTests |
| default·동일값·다른값 | Location 비교 | 정방향 원점, 값 동등성·해시 일치 | LocationTests |
| 제네릭 노드·구간 연결 | 조회 계약·수정 계약·Navigation으로 접근 | 같은 끝점·연결 객체 조회, 위치 변경과 해제 반영 | GenericGeometryTests |
| 위치 조회만 제공하는 구현 | `IReadOnlySegment<TPosition>` 조회 | 회전 계약이나 Segment 기본 클래스 없이 조회 성공 | GenericGeometryTests |
| 다른 위치 타입·폐기 노드 | 연결·위치 편집 | 예외, 기존 연결과 위치 보존 | GenericGeometryTests |
| 범위 밖·허용 오차·폐기 구간 | 제네릭 위치·회전 조회 | 실패 시 기본 출력값, 허용 오차와 수명 계약 유지 | GenericGeometryTests |
| Planar 원본·Pin·Clip·Route | 제네릭 조회 후 원본 이동·경로 비우기 | 위치·회전과 연결 참조 일치, 실패 출력값 초기화 | GenericGeometryTests |
| 공통 Segment·PolySegment 편집 계약 | Planar 구현을 제네릭으로 조회 | Values·Handles·끝점 참조 일치, 읽기 전용 빈 입력과 가변 Poly 입력 구분 | PolySegmentTests |

GraphProject는 노드 3개와 구간 2개에 대한 독립적인 끝점 표로 실제 참조와 열거를 검증한다. 고정 경로는 연결 성공·거부·중복·전체 해제·재생성을 거치며 랜덤 경로도 같은 후보와 검증 조건을 사용한다.
