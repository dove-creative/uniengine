## 제네릭 Route System과 그룹

| 상태 | 동작 | 기대 결과 | 검증 |
| --- | --- | --- | --- |
| 문자열 위치 노드 | NodePin 연결·위치 변경·해제·원본 폐기 | 좌표 연산 없이 추적, 원본 수명 전파 | GenericRouteTests |
| float 위치·bool 회전 | Hold 앵커 교체·Clip·중첩 역방향 Route 조회 | Pin 재사용·교체, 위치·회전·말단·길이 일치 | GenericRouteTests |
| 다른 P·R 또는 간접 자기 의존 | 연결·Append·Pin 재연결 | 기존 참조를 보존하며 거부 | GenericRouteTests |
| 공통 제네릭 Clip | 사용자 Epsilon으로 말단 경계 조회 | 지정한 허용 오차 적용 | GenericRouteTests |
| 공유·중복·값이 같은 별도 원소 | Add·Remove·Clear | 참조 기준 등록 순서, 그래프 연결과 원소 수명 보존 | GroupTests, GroupProject |
| 원소·하위 그룹 폐기 | 폐기 완료 알림 | 모든 부모의 해당 등록 자동 제거 | GroupTests, GroupProject |
| 읽기 전용·위치 전용·Navigation 참조 | 목록 조회 | 동일 목록과 원소, 편집 인터페이스 우회 불가 | GroupTests |
| 공유 하위 그룹·자기 또는 조상 중첩 | 재귀 조회·AddGroup | 참조 중복 제거, 깊이 우선 순서, 순환 거부 | GroupTests |
| 구독 실패·등록 제거·그룹 폐기 | 추가 실패·Remove·Clear·Dispose | 실패 등록과 구독 정리, 원소·하위 그룹 미폐기 | GroupTests |
| 폐기된 그룹 | Add·Remove·Clear·중복 Dispose | 편집 거부, 빈 조회, 중복 정리 허용 | GroupTests, GroupProject |

GroupProject는 세 그룹에 같은 Hold·Route 원소를 등록하고 독립적인 정수 목록으로 직접 등록 순서와 폐기 상태를 대조한다. 기본 경로는 후보의 주요 성공·중복·실패·폐기·재생성을 직접 수행하고, seed 0·1·2는 같은 동작 후보로 각각 깊이 100을 실행한다.
