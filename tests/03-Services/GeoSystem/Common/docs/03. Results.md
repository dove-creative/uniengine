## 중간 실패와 제한

샌드박스의 최초 실행은 VSTest와 testhost가 연결되지 않아 테스트 시작 전에 중단됐다. 같은 산출물을 일반 실행 환경에서 검증했다. 첫 GeoSystem 실행은 38/39 통과였으며 Clip 수명 전파 사례 하나가 실패했다. [초기 사례 기록](Runs/InitialFocused.log)에 해당 결과와 스택을 보존한다. 최종 GeoSystem 실행에서 같은 사례를 포함한 39개 모두 통과했다.

진행 정보를 출력하지 않은 첫 전체 실행은 10분 이상 완료되지 않아 중단했으며 집계 결과를 얻지 못했다. 사례별 로그와 180초 무응답 감지를 추가한 전체 실행은 약 12.82분 후 모두 통과했고 무응답 감지는 발동하지 않았다. 이 중단 실행은 통과 수에 포함하지 않는다.

기존 Dictionary·HashSet·Log의 랜덤 연속 실행이 장시간 실행 구간이었다. 전체 실행이 길어졌을 때 사용자에게 계속 여부를 확인했고, 중단 요청 없이 진행하여 최종 결과를 얻었다. 원본 진행 출력은 tests/bin/GeoSystem/full-progress.log에 있다.

Unity·Mono·IL2CPP, 다중 스레드 편집, 별도 성능·할당 벤치마크와 Project-Index 프로젝트 자체의 실행은 수행하지 않았다.
