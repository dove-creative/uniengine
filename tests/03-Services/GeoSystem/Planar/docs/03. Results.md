## 결과

Planar의 23개 사례가 모두 통과했고 실패·건너뜀은 0개이다. NUnit 직접 사례 19개, UniTest 고정 경로 1개, 랜덤 연속 사례 3개로 구성한다. [사례별 결과](Runs/FocusedFinal.log)를 보관하며 이 결과는 GeoSystem 전체 39개 통과의 부분집합이다. 전체 회귀 상태와 환경 중단 기록은 [공통 결과](../../Common/docs/03.%20Results.md)를 따른다.

직선과 Route의 정·역방향 거리·비율, 도 단위 회전, Clip의 물리적 핀 순서와 조회 방향 조합, 경계 실패·회복, 같은 길이 형상 변경, 원본 재연결·폐기, 반복 Source 구독, 순환 거부와 미구현 끝점 편집의 상태 보존을 확인했다.
