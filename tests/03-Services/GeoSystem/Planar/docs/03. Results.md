# Planar 검증 결과

2026-11-16에 [계획](02.%20Plans.md)을 실행했다. Windows, .NET SDK 10.0.404, Release, 본체 netstandard2.1·테스트 net10.0·C# 9 환경이다.

## 결과

Planar의 23개 사례가 모두 통과했고 실패·건너뜀은 0개이다. NUnit 직접 사례 19개, UniTest 고정 경로 1개, 랜덤 연속 사례 3개로 구성한다. [사례별 결과](Runs/FocusedFinal.log)를 보관하며 이 결과는 GeoSystem 전체 39개 통과의 부분집합이다. 전체 회귀 상태와 환경 중단 기록은 [공통 결과](../../Common/docs/03.%20Results.md)를 따른다.

직선과 Route의 정·역방향 거리·비율, 도 단위 회전, Clip의 물리적 핀 순서와 조회 방향 조합, 경계 실패·회복, 같은 길이 형상 변경, 원본 재연결·폐기, 반복 Source 구독, 순환 거부와 미구현 끝점 편집의 상태 보존을 확인했다.

합계 8,352.691 ms로 중간 확인 기준인 60초 이내이다. 각 seed는 독립적으로 시작했고 고정 경로는 생성 이후 14개 동작을 완료했다. 이력의 부모 ID를 따라 실제 누적 경로를 재구성할 수 있다.

전체 회귀 안에서도 같은 세 seed가 모두 100/100에 도달했으며 실행시간은 각각 3,055.832·3,285.251·3,528.407 ms이다. 이력은 [전체 TRX](../../../../bin/GeoSystem/full-diagnostic.trx)의 사례 출력에 있다.

## 실패와 한계

초기 실행에서 SourceDisposalPropagatesThroughPinsClipHoldAndRoute 사례의 Clip 폐기 검증이 실패했다. 수정본의 해당 단독 사례와 최종 39개 GeoSystem 실행에서 통과했다. 영구 보존한 초기 실패 기록은 [공통 결과](../../Common/docs/03.%20Results.md)에서 확인한다.

PolySegment·곡선·3차원·경로 탐색, Unity·Mono·IL2CPP와 별도 성능 측정은 수행하지 않았다.
