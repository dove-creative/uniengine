## PolySegment와 Shaper

| 대상·상태 | 동작 | 기대 결과 | 검증 |
| --- | --- | --- | --- |
| PolylineShaper·긴 직선 조각 | 목표 길이 변경 | 원본 제어점 보존, 각 조각 균등 분할, 실제 누적 거리 | PolySegmentTests, PolyProject |
| QuadraticBezierShaper·CubicBezierShaper | 제어점 등록·분할 밀도 변경 | 차수별 개수, 알려진 중간점과 독립 수치 적분 길이 일치 | PolySegmentTests, PolyProject |
| Hinge·양끝·내부 경계 | Length·Rate, 정·역 조회 | 정방향 다음 조각·역방향 이전 조각 반전, 끝점 인접 방향 | PolySegmentTests |
| 공개 타입·인터페이스·상속 계약 | Hinge 노출 여부 검사 | Hinge·Hinges 비공개, 생성 훅은 어셈블리 내 파생형에만 허용 | PolySegmentTests |
| Values·Handles·Shaper | 추가·삽입·설정·교체·제거·전체 해제 | 갱신 완료 후 Shape, 무변경 무알림, 입력 참조 보존 | PolySegmentTests, PolyProject |
| 끝점·절대 위치 Handle | 이동·끝점 해제·재연결 | 끝점 Hinge만 노드를 따름, 형상 갱신·무효화·회복 | PolySegmentTests, PolyProject |
| 공유·반복 Handle | 이동·일부 제거·마지막 제거·구간 폐기 | 구간당 한 구독, 마지막 참조 해제, Handle 비소유 | PolySegmentTests |
| Handle 폐기·비유한 위치·제어점 수 불일치 | 입력 편집·제거·Shaper 교체 | 비유한 Planar 설정 거부, 무효 형상 비우기·회복 | PolySegmentTests, PolyProject |
| 연속 중복·모든 점 일치·동일 좌표 끝점 | 조회·Handle 이동 | 계산용 중복 제거, 원본 유지, 영길이 거부·왕복 형상 허용 | PolySegmentTests |
| 0 이하·비유한 목표 길이 | Values 설정 | 예외, 기존 입력·형상·알림 보존 | PolySegmentTests |
| 지나친 분할 요청 | Shaper 직접 호출·설정 복구 | 한도 안에 실패, 출력에 부분 결과 없음, 복구 후 재생성 | PolySegmentTests |
| Pin·Clip·Route·탐색 | 원본 편집·폐기 | 갱신 전파·실제 길이 사용·원본 비소유 | PolySegmentTests, PolyProject |
| 순환·다른 공간 구현 | 끝점 연결 | 연결 전 거부, 기존 참조 보존 | PolySegmentTests |
| Linear·Clip·Route | 공통 편집 계약 접근 | 빈 읽기 전용 Values·Handles | PolySegmentTests |
| 사용자 Shaper·관찰자 예외 | Shaper 교체·Handle 이동 | 생성 예외는 무효 상태 전달, 관찰자 예외는 완료 상태 보존 | PolySegmentTests |
| 누적 편집·재생성 | 고정 경로와 seed 0·1·2 | 독립 입력 모델, 연결·형상·Pin·Route 불변 조건 | PolyProject |

PolyProject는 입력 위치·목표 길이·차수·수명·연결 여부를 별도로 보유한다. PolylineShaper 길이는 원본 점의 거리 합, Bezier 길이는 직접 다항식 평가의 조밀한 수치 근사와 비교한다. 고정 경로는 생성과 20개 동작을 수행하고, 랜덤 경로는 같은 동작 후보로 각 seed마다 깊이 100까지 누적한다.

## Tracer와 Wheel

| 상태 | 동작 | 기대 결과 |
| --- | --- | --- |
| Tracking | 앞선 원본 길이 변경, 뷰 삽입·삭제, 정·역 주행 | RouteBased는 Route 거리를 유지하고 Absolute는 같은 뷰의 말단 위치를 유지한다. |
| Tracking·Rolling | Route 폐기, 말단 폐기, 실패 정책 변경 | 유효한 위치 기준에 따라 상태가 바뀌고 Move는 실제 종료 상태와 잔여 거리를 제공한다. |
| Rolling | 외길·분기점 도달·분기 통과 | 분기 통과만 FIFO 예약을 소비한다. 무예약·무효 예약은 각도와 후보 순서로 결정한다. |
| Rolling | 연결된 Clip 통과, 순환 선로 여러 바퀴 이동 | Clip 위에서는 말단 기준 위치를 제공하고 반대쪽 Pin에서 나온다. 순환 시에도 정확한 끝점과 잔여 거리를 유지한다. |
| 모든 상태 | 배치, 반전, 0·초과 거리, 잘못된 입력 | 유효한 위치에서 반전·끝점 정지, 배치 실패 시 이전 상태 보존, 비유한·음수 거리 거부 |
| 중첩 Route·역방향 Clip·Poly | 경계에서 힌트 변경·형상 교체 | 예약이나 힌트가 다른 조회의 경계 규칙에 영향을 주지 않는다. |
