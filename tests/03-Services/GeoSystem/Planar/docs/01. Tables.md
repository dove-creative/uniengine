# Planar 상태와 동작

| 대상·상태 | 동작 | 기대 결과 | 검증 |
| --- | --- | --- | --- |
| 직선, 정·역방향 × Length·Rate | 위치·변환 조회 | 위치와 도 단위 회전, 역방향 회전 반전 | PlanarGeoSystemTests |
| 경계·영길이·끝점 누락·비유한 입력 | Try 조회 | 경계 허용 오차 제한 또는 false·기본 출력 | PlanarGeoSystemTests |
| 형상 이동·동일 길이 회전 | 노드 편집 | Segment·Pin·Hold·Route의 결과 전파 | PlanarGeoSystemTests, SceneProject |
| Planar·공통·Navigation 인터페이스 | 참조·목록 조회 | 같은 객체, 재귀 없는 열거 | PlanarGeoSystemTests |
| 원본 재연결 | Pin.Connect·Hold.MoveTo | 이전 구독 해제, Hold의 이전 Pin 정리 | PlanarGeoSystemTests, SceneProject |
| 범위 밖 Pin·불완전 원본 | 원본 길이·연결 변경 | 유효성 상실과 회복 | PlanarGeoSystemTests |
| Clip 정·역방향 × 조회 정·역방향 | 위치·변환 조회 | 실제 핀 위치 기준 길이·방향 조합 | PlanarGeoSystemTests |
| Clip의 서로 다른 원본·같은 위치 | 핀 재연결·이동 | 무효 상태에서 정상 상태로 회복 | PlanarGeoSystemTests |
| Route의 순·역 View·경계 | 앞·뒤 추가와 조회 | 끝점·길이·위치·경계 방향 일치 | PlanarGeoSystemTests |
| 반복 Source | 이동·Remove·ClearNodes | 중복 구독 없음, 마지막 참조에서 해제 | PlanarGeoSystemTests, SceneProject |
| Route의 끝점 편집 | TryConnectNode·ConnectNode·DisconnectNode | 전체 재탐색·실패 보존·반대 끝점 유지 | RouteTests, RouteProject |
| 원본 폐기 | Dispose | Pin·Clip·Hold·Route 수명 전파, 원본 노드는 유지 | PlanarGeoSystemTests |
| 간접 자기 참조 | Pin 재연결·끝점 연결·Route 추가 | 변경 전에 순환 거부 | PlanarGeoSystemTests |

SceneProject는 Node→LinearSegment→SegmentPin·Clip→Route 및 Pin→Hold의 통합 상태를 독립적인 시작 좌표·길이·비율·View 방향 목록과 비교한다. 고정 경로와 랜덤 경로는 같은 후보를 사용한다.

## PolySegment와 Shaper

| 대상·상태 | 동작 | 기대 결과 | 검증 |
| --- | --- | --- | --- |
| FreeHandle·긴 직선 조각 | 목표 길이 변경 | 원본 제어점 보존, 각 조각 균등 분할, 실제 누적 거리 | PolySegmentTests, PolyProject |
| Bezier2·Bezier3 | 제어점 등록·분할 밀도 변경 | 차수별 개수, 알려진 중간점과 독립 수치 적분 길이 일치 | PolySegmentTests, PolyProject |
| Hinge·양끝·내부 경계 | Length·Rate, 정·역 조회 | 정방향 다음 조각·역방향 이전 조각 반전, 끝점 인접 방향 | PolySegmentTests |
| Values·Handles·Shaper | 추가·삽입·설정·교체·제거·전체 해제 | 갱신 완료 후 Shape, 무변경 무알림, 입력 참조 보존 | PolySegmentTests, PolyProject |
| 끝점·절대 위치 Handle | 이동·끝점 해제·재연결 | 끝점 Hinge만 노드를 따름, 형상 갱신·무효화·회복 | PolySegmentTests, PolyProject |
| 공유·반복 Handle | 이동·일부 제거·마지막 제거·구간 폐기 | 구간당 한 구독, 마지막 참조 해제, Handle 비소유 | PolySegmentTests |
| Handle 폐기·비유한 위치·제어점 수 불일치 | 입력 편집·제거·Shaper 교체 | 비유한 Planar 설정 거부, 무효 형상 비우기·회복 | PolySegmentTests, PolyProject |
| 연속 중복·모든 점 일치·동일 좌표 끝점 | 조회·Handle 이동 | 계산용 중복 제거, 원본 유지, 영길이 거부·왕복 형상 허용 | PolySegmentTests |
| 0 이하·비유한 목표 길이 | Values 설정 | 예외, 기존 입력·형상·알림 보존 | PolySegmentTests |
| 지나친 분할 요청 | Shaper 직접 호출·설정 복구 | 한도 안에 실패, 출력에 부분 결과 없음, 복구 후 재생성 | PolySegmentTests |
| Pin·Clip·Route·탐색 | 원본 편집·폐기 | 갱신 전파·실제 길이 사용·원본 비소유 | PolySegmentTests, PolyProject |
| 순환·다른 공간 구현 | 끝점 연결 | 연결 전 거부, 기존 참조 보존 | PolySegmentTests |
| Linear·Clip·Route | 공통 편집 계약 접근 | 빈 읽기 전용 Values·Handles | PolySegmentTests |
| 사용자 Shaper·관찰자 예외 | Shaper 교체·Handle 이동 | 생성 예외는 무효 상태 전달, 관찰자 예외는 완료 상태 보존 | PolySegmentTests |
| 누적 편집·재생성 | 고정 경로와 seed 0·1·2 | 독립 입력 모델, 연결·형상·Pin·Route 불변 조건 | PolyProject |

PolyProject는 입력 위치·목표 길이·차수·수명·연결 여부를 별도로 보유한다. FreeHandle 길이는 원본 점의 거리 합, Bezier 길이는 직접 다항식 평가의 조밀한 수치 근사와 비교한다. 고정 경로는 생성과 20개 동작을 수행하고, 랜덤 경로는 같은 동작 후보로 각 seed마다 깊이 100까지 누적한다.
