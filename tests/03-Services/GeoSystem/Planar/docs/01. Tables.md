# Planar 상태와 동작

| 대상·상태 | 동작 | 기대 결과 | 검증 |
| --- | --- | --- | --- |
| 직선, 정·역방향 × Length·Rate | 위치·변환 조회 | 위치와 도 단위 회전, 역방향 회전 반전 | PlanarGeoSystemTests |
| 경계·영길이·끝점 누락·비유한 입력 | Try 조회 | 경계 허용 오차 제한 또는 false·기본 출력 | PlanarGeoSystemTests |
| 형상 이동·동일 길이 회전 | 노드 편집 | Segment·Pin·Hold·Route의 결과 전파 | PlanarGeoSystemTests, SceneProject |
| Planar·공통·Navigation 인터페이스 | 참조·목록 조회 | 같은 객체, 재귀 없는 열거 | PlanarGeoSystemTests |
| 원본 재연결 | Pin.Connect·Hold.MoveTo | 이전 구독 해제, Hold의 이전 Pin 정리 | PlanarGeoSystemTests, SceneProject |
| 범위 밖 Pin·불완전 원본 | 원본 길이·연결 변경 | 유효성 상실과 회복 | PlanarGeoSystemTests |
| Clip 정·역방향 × 조회 정·역방향 | 위치·변환 조회 | 실제 핀 위치 기준 길이·방향 조합 | PlanarGeoSystemTests |
| Clip의 서로 다른 원본·같은 위치 | 핀 재연결·이동 | 무효 상태에서 정상 상태로 회복 | PlanarGeoSystemTests |
| Route의 순·역 View·경계 | 앞·뒤 추가와 조회 | 끝점·길이·위치·경계 방향 일치 | PlanarGeoSystemTests |
| 반복 Source | 이동·Remove·ClearNodes | 중복 구독 없음, 마지막 참조에서 해제 | PlanarGeoSystemTests, SceneProject |
| Route의 경로 탐색 미구현 | ConnectNode·DisconnectNode | NotImplementedException, 목록 보존 | PlanarGeoSystemTests |
| 원본 폐기 | Dispose | Pin·Clip·Hold·Route 수명 전파, 원본 노드는 유지 | PlanarGeoSystemTests |
| 간접 자기 참조 | Pin 재연결·끝점 연결·Route 추가 | 변경 전에 순환 거부 | PlanarGeoSystemTests |

SceneProject는 Node→LinearSegment→SegmentPin·Clip→Route 및 Pin→Hold의 통합 상태를 독립적인 시작 좌표·길이·비율·View 방향 목록과 비교한다. 고정 경로와 랜덤 경로는 같은 후보를 사용한다.
