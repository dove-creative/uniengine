# Scp 이관 검증 계획

## 범위

UniEngine MVP의 기존 NUnit 테스트 5개를 현재 UniEngine.Tests 프로젝트로 이관한다. Scp 초안의 기존 동작 보존을 확인하며 정식 실행 계약이나 새로운 UniTest 상태 전이 테스트는 작성하지 않는다.

## 기존 사례

| 사례 | 확인 범위 |
| --- | --- |
| Normal | 클립의 분기·합류가 제한된 갱신 횟수 안에 마지막 클립까지 도달한다. |
| Recurse | 단일 클립이 제한된 갱신 횟수 안에 종료한다. 기존 이름을 유지하며 재시작·재귀를 검증하는 사례는 아니다. |
| Sequence_ExecutesSuccessorsAndReportsCompletion | 선행·후속 클립의 실행 순서와 완료 보고를 확인한다. |
| Sequence_StopIsIdempotentAndDisallowsMutationWhileActive | 실행 중 등록 금지, 시퀀스의 중복 Stop, 다시 Start할 수 있는지를 확인한다. 재시작 이후의 갱신은 검증하지 않는다. |
| Sequence_FailingClipStopsOthersAndReportsException | 갱신 예외를 보고하고 실행 중인 다른 클립을 정지한다. |

## 실행

저장소 루트에서 실행한다. 본체는 테스트 프로젝트의 ProjectReference를 통해 함께 빌드한다.

```powershell
dotnet build tests/UniEngine.Tests.csproj -c Release
dotnet test tests/UniEngine.Tests.csproj -c Release --no-build --filter TestCategory=Scp --logger "trx;LogFileName=scp-verified.trx" --results-directory tests/bin/ScpResults
dotnet test tests/UniEngine.Tests.csproj -c Release --no-build --logger "trx;LogFileName=all.trx" --results-directory tests/bin/ScpResults
```

새 공개 API를 본체에 포함하므로 전체 회귀도 한 번 실행한다. 기존 Scp 사례 5개와 전체 회귀가 실패·건너뜀 없이 통과하는 것을 기대한다.

## 정적 검사와 한계

- 원본과 비교하여 네임스페이스·using·테스트 분류 외의 실행 로직 변경이 없는지 확인한다. Delay와 IsExternalInit도 원본과 비교한다.
- 이관한 C# 파일의 UTF-8·LF·공백과 변경 문서의 링크를 확인한다.
- Delay의 별도 동작 테스트, 재시작 후 남은 토큰, 토큰 소비·버전, 시작·정리 중 예외와 재진입은 이번 검증에 포함하지 않는다.
- Unity·Mono·IL2CPP 실행과 새 성능 측정은 수행하지 않는다. 기존 전체 회귀에 포함된 할당량 검증은 그대로 실행한다.

실제 집계와 한계는 [검증 결과](03.%20Results.md)에 기록한다.
