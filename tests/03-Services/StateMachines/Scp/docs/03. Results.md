# Scp 이관 검증 결과

2026-11-15에 [이관 검증 계획](02.%20Plans.md)에 따라 실행한 결과이다.

## 실행 환경

- Windows, .NET SDK 10.0.404, Release.
- 본체 netstandard2.1, 테스트 net10.0, C# 9.
- 기존 복원 결과를 사용하여 테스트 프로젝트를 --no-restore로 빌드하였다. 본체도 ProjectReference를 통해 함께 빌드하였다.

## 결과

| 검증 | 결과 |
| --- | --- |
| 본체·테스트 Release 빌드 | 성공, 경고 0개·오류 0개 |
| Scp 기존 NUnit 사례 | 5개 통과, 실패·건너뜀 0개 |
| 전체 회귀 | 1,452개 통과, 실패·건너뜀 0개. 이관한 Scp 5개 포함 |
| 원본 비교 | 네임스페이스·using·테스트 클래스 이름·카테고리 외 실행 로직 변경 없음 |

Scp의 TRX 실행 구간은 2.388초이며 테스트 러너의 본문 표시 시간은 31 ms이다. 전체 회귀의 TRX 실행 구간은 211.858초이며 본문 표시 시간은 3분 30초이다. TRX 실행 구간은 start부터 finish까지로 계산한다. [Scp TRX](../../../../bin/ScpResults/scp-verified.trx)와 [전체 회귀 TRX](../../../../bin/ScpResults/all.trx)에 사례별 결과를 보관한다.

## 중단과 재실행

최초 샌드박스 실행은 vstest.console이 testhost에 연결하지 못해 90초 후 중단되었다. 이 실행의 테스트 수와 실행 수는 모두 0이다. [최초 실행 TRX](../../../../bin/ScpResults/scp.trx)를 보존하고, 샌드박스 밖에서 같은 Scp 테스트를 다시 실행하여 5개 통과를 확인하였다.

## 한계

정식 생애주기 계약을 확정하거나 기존 동작을 수정한 검증이 아니다. 재시작 후 남은 토큰·토큰 버전과 소비·시작 또는 정리 중 예외·재진입은 검증하지 않았다. Delay는 원본 코드와의 비교와 빌드만 확인하였다.

Unity·Mono·IL2CPP 실행과 새 성능 측정은 수행하지 않았다. 실행 산출물인 TRX는 tests/bin에 있으며 Git에 포함하지 않는다.
