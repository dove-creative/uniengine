# USM 검증 결과

2026-11-15 초기 NodeBuilder 기반 마이그레이션 당시의 검증 결과이다. 현재 TTC API의 결과는 [현재 검증 결과](03.%20Results.md)에 있다.

## 실행 환경

- Windows, .NET SDK 10.0.404.
- 본체 netstandard2.1, 테스트 net10.0, C# 9, Release 구성.
- NUnit 직접 사례 48개, UniTest 고정 경로 1개, 랜덤 연속 사례 3개로 USM 검증을 구성하였다.

## 결과

| 검증 | 결과 |
| --- | --- |
| 본체 Release 빌드 | 성공, 경고 0개·오류 0개 |
| USM 전체 | 52개 통과, 실패·건너뜀 0개, 테스트 실행 약 2초 |
| 저장소 전체 회귀 | 1,388개 통과, 실패·건너뜀 0개, 테스트 실행 약 3분 9초 |
| 소스 형식 | 추가 C# 파일 24개가 UTF-8·LF이며 줄 끝 공백 없음 |
| 변경 공백 검사 | git diff --check 통과 |
| 의존 범위 | USM 소스에 EventStream·Injection·Reframe 참조 없음 |

USM 사례별 결과·소요시간은 [개별 실행 기록](Runs/UsmResults.log), 전체 회귀 집계는 [전체 실행 기록](Runs/FullSuite.log)에 보관한다. 로컬 TRX 원본은 `tests/bin/UsmResults/usm.trx`와 `tests/bin/UsmResults/all.trx`이며 빌드 산출물이므로 버전 관리에 포함하지 않는다.

## 중단과 한계

초기 샌드박스 실행은 testhost 연결이 90초 내에 완료되지 않아 테스트 본문 실행 전에 중단되었다. 일반 실행 환경에서 USM 검증과 전체 회귀를 완료하였다.

Unity 실행·Mono·IL2CPP, 멀티스레드 사용, 성능·할당 측정은 수행하지 않았다. 실행 횟수 제한은 동기 콜백의 실행시간을 제한하지 않는다.
