# Adaptive Collections 검증 결과

## 랜덤 연속 테스트 검증

2026-11-10에 .NET SDK 10.0.403 Release에서 지연·즉시 반영 모드의 랜덤 연속 테스트를 모듈 필터로 실행했다. 모든 seed가 계획 깊이 100에 도달했으며 6개 통과, 실패·건너뜀 0개이다.

| 반영 모드 | seed 0 | seed 1 | seed 2 |
| --- | ---: | ---: | ---: |
| 즉시 | 175.966 ms | 134.983 ms | 194.911 ms |
| 지연 | 268.409 ms | 199.614 ms | 177.238 ms |

각 동작의 방문 순서와 순회 후 목록·개수를 기대 목록과 대조했다. 시간은 빌드와 복원을 제외한 UniTest 실행 기준이다. seed별 동작과 결과는 [Adaptive Collections 랜덤 실행 TRX](../../../obj/RandomContinuous/adaptive-collections.trx)의 NUnit 출력에 기록했다. 각 행의 부모 노드 ID를 따라 해당 후보까지의 실행 경로를 확인할 수 있다.
