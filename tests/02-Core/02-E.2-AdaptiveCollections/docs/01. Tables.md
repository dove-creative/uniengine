# Adaptive Collections 상태와 동작

## 목차

- 범위

## 범위

목록·사전·집합의 순회 계약과 AdaptiveAction의 호출 목록 캐시·회귀 동작을 검증한다. 공통 열거자의 계약은 [ValueEnumerator 상태와 동작](../../01-O.3-Objects/docs/01.%20Tables.md)에서, EventStream의 구독 변경 회귀는 [EventStream 상태와 동작](../../02-E.3-EventStream/docs/01.%20Tables.md)에서 다룬다.

| ID | 상태·동작 | 기대 결과 |
| --- | --- | --- |
| C1 | 빈 목록·일반 목록·중복·null | 원래 값과 순서를 유지한다. |
| C2 | 지연·즉시 모드의 추가와 조회 | 추가 반영 시점 및 Count·Contains·CopyTo 결과를 유지한다. |
| C3 | 이전·현재·다음 항목 및 대기 항목 삭제 | 방문할 유효 항목을 누락하거나 중복하지 않는다. |
| C4 | Clear 이후 추가 | 현재 순회는 중단하고 이후 추가는 다음 순회에서 읽는다. |
| C5 | 정상·break·예외 종료 | 대기 항목을 반영하고 다음 순회를 허용한다. |
| C6 | 중첩 순회 시작 실패 | 기존 순회는 계속되고 실패한 열거자는 다른 순회를 종료하지 않는다. |
| C7 | 구조체 복사·오래된 식별자 | 하나의 순회를 공유하고 반복 종료는 무시하며 오래된 이동은 거부한다. |
| C8 | 인터페이스 순회·Reset·ForEach | 기존 순회 기능을 유지하고 Reset은 지원하지 않는다. |
| A1 | 변경 없는 직접 순회 | 워밍업 이후 열거자 경로의 할당량은 0바이트이다. |
| D1 | 사전의 추가·교체·삭제·후속 묶음 | 지연·즉시 반영 정책과 논리 조회를 유지한다. |
| H1 | 집합의 중복·null·삭제·재추가·후속 묶음 | 유일성, 제거 표시와 방문 정책을 유지한다. |
| B1 | 사전·집합의 수명·중단·실패·인터페이스 | 지연 시작, 중첩 거부, 오래된 ID 방어와 정리를 유지한다. |
| A2 | 사전·집합의 직접 순회와 반복 변경 | 필요한 버퍼 용량 확보 후 10,000회 반복 구간에서 0바이트이다. 제거 기록이 남은 뒤 기본 동등성을 쓰는 구조체를 순회해도 0바이트이다. |
| A3 | Action 등록 경로와 첫 호출·반복 호출 | 인자 0~3개, 기본 클래스·인터페이스·일괄 등록에서 첫 Invoke와 반복 Invoke에 할당이 없다. |
| A4 | Action 캐시 수명·부분 등록·자기 추가 | 등록 중 실패한 부분도 준비하며, 중복 등록의 의미와 제거된 콜백의 수거 가능성을 유지한다. |
| R1 | AdaptiveAction 자기 제거·추가·예외·재진입 | 현재 항목 활성 상태, 지연 추가 및 예외 처리 정책을 유지한다. |
| U1 | UniTest 상태 전이 | 생성 → 추가하며 순회 → 삭제하며 순회를 재현하고 검증한다. |
