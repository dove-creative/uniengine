## 실행 환경과 범위

2026-11-14에 Windows·.NET SDK 10.0.404·Release 구성으로 [테스트 계획](02.%20Plans.md)을 실행했다. 대상은 Property와 IPropertySubject 소비 시나리오이며, 본체 netstandard2.1과 테스트 net10.0을 빌드했다.

시간은 공통 실행기가 ExecuteContinuously 호출 구간에서 측정한 값이며 빌드·복원 시간은 포함하지 않는다.

세 seed의 합계는 3,853.643 ms로 중간 확인 기준 60초 이내이다. 중단되거나 목표 깊이에 도달하지 못한 연속 실행은 없다. 각 후보의 노드 ID·부모 ID·깊이·상태·Lab ID는 [실행 TRX](../../../bin/TestResults/Property/Property.trx)의 사례별 StdOut에 기록되어 있다.

## 실행 기록과 한계

최초 계획 명령은 빌드에 성공했으나, 샌드박스 안에서 VSTest가 testhost에 90초 동안 연결하지 못해 테스트 시작 전에 중단됐다. [최초 중단 TRX](../../../bin/TestResults/Property/Property-sandbox.trx)

이후 같은 빌드 결과를 사용하여 샌드박스 밖에서 다음 명령을 실행했고 47개가 모두 통과했다.

```powershell
dotnet test tests/UniEngine.Tests.csproj -c Release --no-build --no-restore --filter 'FullyQualifiedName~BlackThunder.UniEngine.Tests.Property' --results-directory tests/bin/TestResults/Property --logger 'trx;LogFileName=Property.trx'
```

최초 복원·빌드 과정에서 api.nuget.org에 연결하지 못해 패키지 취약성 정보를 조회할 수 없다는 NU1900 경고가 있었다. 컴파일 오류는 없었다. 다른 모듈 전체 테스트, Unity 실행, 성능·동시성 검증은 이번 범위에 포함하지 않았다. TRX는 로컬 빌드 산출물 경로에 있으며 정리 시 제거될 수 있다.
