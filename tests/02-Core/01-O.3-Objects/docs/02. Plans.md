# ValueEnumerator 테스트 계획

## 목차

- 실행 구성
- 검증 기준

## 실행 구성

테스트는 단일 프로젝트 `tests/UniEngine.Tests.csproj`에서 소유하고, 본체를 ProjectReference로 연결한다. NUnit 3 실행기를 사용하며 .NET 10 SDK로 실행한다.

| 테스트 파일 | 표의 범위 | 구현 방향 |
| --- | --- | --- |
| [ValueEnumeratorTests](../ValueEnumeratorTests.cs) | V1–V3 | 컬렉션과 독립된 소스 및 실패 주입으로 지연 시작·정리 책임을 검증한다. |

## 검증 기준

- 공개 API 변경이므로 추가한 테스트 전체를 Release로 실행한다.
- 본체가 C# 9·.NET Standard 2.1을 대상으로 하므로, 공통 계약과 구조체의 호환성은 본체 Release 빌드로 함께 확인한다.
