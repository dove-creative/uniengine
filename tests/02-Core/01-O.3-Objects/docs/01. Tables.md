# ValueEnumerator 상태와 동작

- 범위

## 범위

공통 ValueEnumerator의 지연 시작, 순회, 정리 계약을 검증한다. 목록·사전·집합에서의 순회는 [Adaptive Collections 상태와 동작](../../02-E.2-AdaptiveCollections/docs/01.%20Tables.md)에서 다룬다.

| ID | 상태·동작 | 기대 결과 |
| --- | --- | --- |
| V1 | 생성·기본값·시작 전 폐기 | 지연 시작, 기본값은 빈 순회, null 생성자는 거부한다. |
| V2 | 독립 소스의 이동·정상 종료 | 값의 순서를 유지하고 종료를 한 번 수행한다. Current는 마지막 값을 유지한다. |
| V3 | 시작·이동·종료 실패 | 획득 실패는 다른 순회를 정리하지 않고, 획득 이후 실패는 상태를 정리한다. |
