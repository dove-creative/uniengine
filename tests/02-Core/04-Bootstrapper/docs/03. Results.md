# Bootstrapper 검증 결과

## 실행 결과

2026-11-15, Windows·.NET SDK 10.0.404·Release 기준이다. 본체 netstandard2.1과 테스트 net10.0 빌드가 경고·오류 없이 통과했다.

| 범위 | 통과 / 실행 | 결과 |
| --- | ---: | --- |
| Bootstrapper NUnit 직접 사례 | 17 / 17 | 기본값, 순서, 콜백·로거 실패, 정리 실패, 중복·동시·재진입·전파 중 호출이 통과했다. |
| Configuration NUnit 직접 사례 | 8 / 8 | 기존 단일 인자 API와 설치 경로 정규화·검증·실패 후 복구가 통과했다. |
| Configuration UniTest 사례 | 4 / 4 | 기존 직접 상태 경로와 seed 0·1·2가 통과했다. |
| 전체 일반 테스트 | 1,277 / 1,277 | 실패·건너뜀 0개이며 실행기 기준 약 1분 33초이다. |

각 모듈 수는 전체 실행의 부분집합이며 서로 더하지 않는다. Bootstrapper 초기화 실패는 등록된 예외 정책에 보고되지 않고 호출자에게 전달됐다. Main 정리 대상 Handle이 자신의 콜백 실패를 보고하는 기존 동작은 유지됐으며, Bootstrapper는 초기화 실패와 정리 실패를 순서대로 보존했다.

## 초기 실패와 재검증

최초 전체 실행은 1,276개 통과·1개 실패였다. Defaults 사례가 테스트용 AssemblyBuilder를 SetEntryAssembly에 넘겨 제품 초기화 전에 ArgumentException으로 실패했다. 테스트가 생성한 타입의 런타임 어셈블리를 넘기도록 수정한 뒤 Bootstrapper 선택 실행 17개와 최종 전체 실행 1,277개가 모두 통과했다. 이 수정은 테스트 준비에 한정했다.

최종 전체 실행의 Log 랜덤 연속 세 seed 시간 합계는 70.660초였다. 60초 초과는 전체 실행 완료 후 확인했다.

## 검증 범위

변경한 코드 7개 파일의 LF·후행 공백·120자 줄 길이를 확인했다. 기존 수학 문서와 다이어그램 두 파일은 작업 전후 SHA-256이 일치했다. Unity 실행과 벤치마크는 이번 검증 범위에 포함하지 않았다.
