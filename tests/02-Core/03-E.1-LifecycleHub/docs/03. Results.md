# LifecycleHub UniTest 검증 결과

## 실행 결과

2026-11-15, Windows·.NET SDK 10.0.404·Release에서 [계획](02.%20Plans.md)의 U1–U5를 실행했다. 고정 경로 1개와 랜덤 연속 경로 3개, 총 4개가 모두 통과했으며 실패·건너뜀은 0개이다. 고정 경로는 생성 포함 깊이 34까지 모든 동작을 직접 실행한다.

| seed | 실제 깊이 / 목표 깊이 | 실행시간 | 결과 |
| --- | --- | ---: | --- |
| 0 | 100 / 100 | 762.834 ms | 통과 |
| 1 | 100 / 100 | 805.867 ms | 통과 |
| 2 | 100 / 100 | 755.453 ms | 통과 |

시간은 공통 실행기가 ExecuteContinuously 호출 구간에서 측정했다. 세 seed의 합계는 2,324.154 ms로 60초 이내이다. 중단하거나 목표 깊이에 도달하지 못한 연속 실행은 없다.

독립 등록표와 콜백별 누적 횟수를 통해 직접·client·null 등록, 교차 중복·해제·재등록, 정상·예외·재진입 폐기, 반복 폐기와 저장된 Builder의 등록 거부를 검증했다. 완료된 허브를 확인한 뒤 새 허브에서도 수명을 이어갔다. 등록 간 통지 순서는 가정하지 않는다.

재실행으로 생성한 미완료 허브도 등록 해제 후 폐기한다. 전역 예외 처리기를 사용하는 사례는 병렬 실행하지 않으며 임시 정책과 사례 전후에 기본 정책을 복구한다. 처리되는 실패 사례는 지정한 예외만 수집하므로 다른 단언 실패가 성공으로 처리되지 않는다.
