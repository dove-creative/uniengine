## 실행 구성

[EventHubTests](../EventHubTests.cs)와 [EventHubFlagsTests](../EventHubFlagsTests.cs)를 NUnit 직접 사례로 실행하고, [EventHubRandomContinuousTests](../EventHubRandomContinuousTests.cs)에서 결합형 등록의 랜덤 연속 사례를 실행한다. 본체는 ProjectReference로 연결하며, 테스트 프로젝트는 .NET 10·C# 9이다. LifecycleHub 사례는 [별도 테스트](../../03-E.1-LifecycleHub/docs/02.%20Plans.md)로 분리한다. 기준은 [상태·동작 표](01.%20Tables.md)이다.

## 검증 방법

- 테스트 클래스 전체를 NonParallelizable로 두고 각 사례 전후 ExceptionHandler를 초기화한다. 전역 처리기의 상태가 다른 사례에 남지 않게 한다.
- Debug 검사에서 바꾼 Console.Out은 finally에서 복원한다.
- 할당 측정 구간에 등록·단언·출력·대리자 생성을 넣지 않는다. Debug와 object 박싱은 무할당 측정에서 제외한다.
- 참조 수거 검사는 NoInlining 보조 메서드에서 대상을 등록하여 호출자 스택에 대상의 강한 참조가 남지 않게 한다.
- 해제 알림 전환의 추가 사례는 NUnit 직접 사례 6개 메서드·11개 실행 조합이다. 기존 FailedUpdateCanBeRegisteredAgainDuringTheSameUpdate의 Builder 조합만 즉시 해제 계약에 맞춰 기대값을 바꾸며, 직접 구독 조합과 나머지 기존 기대값은 유지한다.
- OnFlags 통합 사례는 공개 Builder 호출과 수신·조건 평가 이력으로 검증한다. 별도 IEventHubBuilder&lt;ulong&gt; 구현의 NotSupportedException 계약은 위 직접 사례의 실행 범위에 포함하지 않는다.
- 공개 API 변경이나 여러 모듈에 걸친 변경은 전체 Release 테스트로 확인한다. 장시간 벤치마크와 외부 장비 테스트는 이 계획에 포함하지 않는다.
- 랜덤 연속 테스트는 RandomContinuous 범주로 표시한다. seed 0·1·2의 실제 테스트 실행시간 합계가 60초를 넘으면 [공통 테스트 안내](../../../README.md)의 중간 확인 규칙을 따른다. 빌드·복원 시간은 제외하며 seed·도달 깊이·실행시간·이력을 TRX에 기록한다.
- Builder의 조건·콜백 결합형 전환은 C1–C6·U1–U10·K1–K9·D4–D6·L1과 R1에서 연결 수명, 조건 값 중복, 노드 공유, 콜백 형식과 생애주기를 확인한다. 이전 구현의 갱신·수면·폐기·실패·할당 사례도 함께 유지한다.
- 값 조건의 When 전환은 U7–U10·D5·K8·R1에서 확인한다. 중복 판정은 기존 값 기준을 유지하며 별도 조건과 target 단축형도 같은 위치의 같은 target 경로를 공유한다. 처리량 비교, 벤치마크 및 Unity Mono·IL2CPP의 할당 검증은 실행 범위에 포함하지 않는다.

## 실행과 기록

```powershell
dotnet build src/UniEngine.sln -c Release
dotnet test tests/UniEngine.Tests.csproj -c Release --filter FullyQualifiedName~EventHub --logger 'trx;LogFileName=EventHub.trx' --results-directory tests/bin/TestResults/EventHubConditions
dotnet test tests/UniEngine.Tests.csproj -c Release --logger 'trx;LogFileName=All.trx' --results-directory tests/bin/TestResults/EventHubConditions
```

테스트에는 .NET 10 SDK를 사용한다. 기본 dotnet이 .NET 9라면 [공통 실행 안내](../../../README.md)의 사용자 위치 .NET 10 실행 파일을 사용한다. [검증 결과](../../docs/Hub%20Results.md)에 실행 날짜·환경·통과 수·경고와 랜덤 연속 사례의 seed·깊이·실행시간을 기록한다. 원본 TRX는 .gitignore가 제외하는 tests/bin 아래의 산출물이며 버전 관리에 포함하지 않는다.
