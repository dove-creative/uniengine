## 기본 틱 스트림 검증

2026-11-15 Release 전체 일반 테스트 1,258개가 모두 통과했으며 실패·건너뜀은 없다. EventStream 377개는 전체 실행의 부분집합이고, 그 안에 Main의 NUnit 직접 사례 15개가 포함된다. Main 참조 유지·float 전달·필터와 enum 순서, 초기화 시 기존 연결 정리와 알림 부재, 독립 스트림 보존, 반복 초기화와 종료 후 복구가 통과했다. Main과 다른 스트림의 동기·병렬·완료·오류 콜백에서 초기화를 거부하고 전파 후 초기화하는 사례도 통과했다.

최초 샌드박스 실행은 테스트 어셈블리 컴파일 후 testhost 연결을 90초 기다리다 중단됐으며 실제 테스트 사례를 실행하지 못했다. 이 시도는 최종 통과 수에 포함하지 않는다. 이후 동일 Release 바이너리를 샌드박스 밖에서 `--no-build --no-restore`로 재실행하여 위 결과를 얻었다.

전체 실행에 포함된 Log 랜덤 연속 검증의 세 seed 실행시간 합계는 66.249초였다. 60초 초과는 전체 실행이 끝난 뒤 집계하면서 확인했다.

추가·수정한 로컬 문서 링크와 앵커를 확인했으며, 새 코드 두 파일의 LF와 기존 다이어그램 두 파일의 SHA-256 일치를 확인했다. 벤치마크와 Unity 실행은 이번 검증 범위에 포함하지 않았다.

## 검증 범위와 한계

- 기능·할당 결과는 Windows·.NET 10 Release에서 확인한 것이다. Unity Mono·IL2CPP의 동작·할당·스택 여유와 실게임 프레임 비용은 검증하지 않았다.
- 2026-11-12 노드 통합 후에는 모듈 319개를 실행했다. 전체 1,059개 결과와 구조 비교 수치는 그 이전 키 행 구조의 기록이며, 노드 통합 후 벤치마크는 재측정하지 않았다.
- 두 OOP·JIT 비교에서는 기능 테스트를 재실행하지 않았다. 소규모 OOP 비교는 1,000명 이하 대표 시나리오에 한정된다.
- When과 Where·ForFlags 사이의 속도 차이, PathInfo 크기, JIT의 구체적인 PGO 최적화는 확인하지 않았다. 발행 할당 수치에는 준비·등록, Debug 문자열·로그, 사용자 비교 함수의 할당을 포함하지 않는다.
