## NUnit 직접 사례

[상태·동작 표](01.%20Tables.md)의 스트림과 그래프를 공개 API로 구성한다. 경로 공유·정리 여부는 internal NodeCount와 관찰자의 수신 이력을 함께 확인한다.

| 범위 | 테스트 파일 | 검증 대상 |
| --- | --- | --- |
| C1–C7 | [스트림 연결](../EventStreamConnectionTests.cs) · [그래프 수명](../EventStreamLifecycleTests.cs) | 새 스트림의 연결과 해제, 종료 전달, 외부 공급원 비소유, 직접 입력, 수신자로서의 동작을 검증한다. |
| O1–O5 | [연산자](../EventStreamOperatorTests.cs) · [그래프](../EventStreamGraphTests.cs) | 조건 참조 공유, 거짓 조건 아래 가지치기, 상태 연산자의 상태 공유와 수명, Debug 전달을 확인한다. |
| O6 | [구독 전 입력](../EventStreamPendingInputTests.cs) | DirectInputAdvancesCountersBeforeSubscription, DirectInputEvaluatesConditionsBeforeSubscription, TakeCanFinishBeforeItsFirstSubscription으로 직접 입력·비활성 입력·구독 전 종료를 검증한다. |
| Where 색인 | [조건 색인](../EventStreamWhereIndexTests.cs) | 조건 8·16·17·32·33·64개에서 대리자 동등성을 확인한다. 멀티캐스트 순서와 부모별 공유 범위, 전파 중 색인 생성·재등록, 축소·전체 해제·예외 정리 뒤의 재사용, 제거된 부모의 참조 회수를 검증한다. |
| I1–I4 | [순서 그룹과 필터](../EventStreamCompositionTests.cs) | 그룹마다 같은 조건을 따로 평가하고, Branch 경로를 독립적으로 해제한다. |
| F1–F2와 전파 | [스트림과 그룹](../EventStreamPropagationTests.cs) · [그래프 전파](../EventStreamGraphPropagationTests.cs) | 추가는 다음 발행부터, 제거는 즉시 반영한다. 멀티캐스트·재진입·예외·참조 회수와 실패 뒤의 전파를 확인한다. |
| F3 | [그래프 전파](../EventStreamGraphPropagationTests.cs) | FinalTakePreservesFirstFailureAcrossValueAndCompletion으로 직접·상위 입력과 미처리·처리·보고기 실패를 조합한다. FinalTakeStillPropagatesCompletionFailure로 완료만 실패하는 경우도 확인한다. |
| M1–M2 | [기본 동작과 Merge](../EventStreamTests.cs) · [그래프 수명](../EventStreamLifecycleTests.cs) | 폐기된 입력 거부, 입력별 완료·폐기, 입력별 전달을 검증한다. |
| R1 | [기본 동작과 Merge](../EventStreamTests.cs) | EventStreamAppliesSubscriptionChangesAtTheExpectedTime, EventStreamRecoversAfterCallbackFailure, EventStreamDisposalDuringPublicationStopsRemainingCallbacks로 구독 변경의 반영 시점, 콜백 실패 뒤의 복구, 발행 중 폐기를 검증한다. |
| 할당 | [스트림·순서 그룹](../EventStreamAllocationTests.cs) · [그래프·Branch](../EventStreamGraphAllocationTests.cs) | 별도 인스턴스를 예열한 뒤 첫·반복 전파의 할당량을 측정한다. 마지막 Take(1)가 Branch를 완료·폐기하는 경우도 포함한다. |

## UniTest 실행 경로

세 프로젝트는 CompactProject와 CompactLab을 Inline 모드에서 실행한다. 각 경로에서 이전 동작을 재현한 상태에 다음 Lab을 적용하며, 값·종료 통지·연결 수·폐기 상태와 실제 종료 이력 목록을 확인한다. 실행 후 모든 재현 모델의 스트림을 정리한다.

[Branch 프로젝트](../UniTest/EventStreamStateProjectTests.cs)는 기존 두 종료 경로를 유지한다.

| 구간 | Lab 순서 |
| --- | --- |
| 공통 | SubscribePair → ReleaseFirst → PublishWhileDisabled |
| U1 | ResumePublication → ReleaseLast |
| U2 | CompleteWhileDisabled |

[Merge 프로젝트](../UniTest/EventStreamMergeStateProjectTests.cs)의 MergeLifetimesSucceedThroughUniTest는 아홉 종료 이력을 확인한다.

| 구간 | Lab 순서 |
| --- | --- |
| 공통 | ConnectPair |
| UM1–UM8 | CompleteFirst 또는 DisposeFirst → ContinueRemaining → CompleteLast·DisposeLast·ErrorLast·ReleaseLast 중 하나 |
| UM9 | ReleaseBothInputs |

[상태 연산자 프로젝트](../UniTest/EventStreamOperatorStateProjectTests.cs)의 StatefulOperatorLifetimesSucceedThroughUniTest는 네 연산자를 NUnit 매개변수로 실행하고 합계 여섯 종료 이력을 확인한다.

| 구간 | Lab 순서 |
| --- | --- |
| 공통 | PrimeDirectInput → SubscribeAndAdvance → DisableInputs → ResumeAndSubscribeLate |
| US1 | PublishRemaining으로 Take 완료 |
| US2 | PublishRemaining → ReleaseLast |
| US3 | PublishRemaining → CloseCondition |
| US4 | PublishRemaining → PublishAfterOpenAndRelease |
| US5–US6 | FailCondition으로 TakeWhile·SkipWhile 실패 |
