# EventStream 상태와 동작

## 목차

1. 스트림과 그래프의 공개 계약
2. Branch 수명 상태 전이

## 스트림과 그래프의 공개 계약

EventStream은 값을 받아 그래프로 전달한다. Where와 Debug는 경로를 만들고, Take·TakeWhile·Skip·SkipWhile·Branch·Merge는 새 스트림을 시작한다.

| ID | 상태와 동작 | 기대 결과 |
| --- | --- | --- |
| C1 | 새 스트림에 구독한 뒤 구독을 하나씩 해제한다. | 마지막 구독을 해제할 때까지 상위 연결을 유지한다. 해제 후 상위의 노드는 없어지고 상위는 그대로 살아 있다. |
| C4 | 비활성 상위에 값을 보낸 뒤 완료 또는 오류를 알린다. | 값은 건너뛰고 종료 신호는 연결된 스트림에 전달한다. |
| C5 | 상위를 명시적으로 폐기한다. | 상위가 만든 스트림은 통지 없이 폐기된다. 생성자로 상위를 받은 독립 스트림은 살아 있고 값을 직접 받을 수 있다. |
| C6 | 새 스트림과 외부 입력 스트림에 OnNext로 값을 직접 넣는다. | 위에서 온 값과 같게 처리하고 그 스트림 아래로만 전달한다. Take·Skip은 횟수에 포함하고, TakeWhile·SkipWhile은 조건을 평가하며, 비활성 스트림은 값을 세지 않는다. 같은 스트림의 전파 중 입력은 거부한다. |
| C7 | 스트림을 다른 스트림의 Subscribe에 수신자로 넘긴다. | 값과 종료 신호를 받는다. 연결은 반환된 핸들로 해제하고, 폐기된 수신자 스트림은 일반 구독의 실패처럼 해제된다. |
| O1 | Where와 SkipWhile에 같은 조건 변화를 준다. | Where는 들어온 값마다 검사한다. SkipWhile은 첫 false부터 이후 값도 그대로 전달한다. |
| O2 | 양수·0·음수 횟수로 Take·Skip을 만들고 같은 스트림에 뒤늦게 구독한다. | 같은 스트림의 구독자는 상태를 공유하고, 연산자를 다시 호출하면 새 상태로 시작한다. 횟수는 첫 구독부터 센다. 0 이하의 Take는 첫 활성 입력에서 값 없이 완료한다. 끝난 스트림의 구독은 거부한다. |
| O3 | TakeWhile 조건을 닫은 뒤 다시 연다. | 첫 false에서 그 스트림만 완료·폐기한다. 상위의 다른 구독자는 이후 값도 받는다. |
| O4 | 같은 부모에서 Branch를 두 번 만들고 마지막 구독을 해제한다. | 첫 구독까지 부모의 값 경로를 만들지 않는다. 한 Branch의 마지막 해제는 이웃에 영향을 주지 않는다. 부모 종료는 구독 전 Branch의 수명에도 적용된다. |
| O5 | Where 뒤 Debug에 일치·불일치 값을 전달한다. | 통과한 값만 지정한 메시지로 기록하고 원래 값을 전달한다. |
| I1 | 같은 Filter를 두 순서 그룹에 등록하고 한 그룹에서 다시 사용한다. | 같은 그룹에서 조건을 한 번 평가하고 다른 그룹에서는 따로 평가한다. 그룹 등록 순서대로 방문한다. |
| I2 | 마스크 조건의 Branch에 구독한 뒤 마지막 구독을 해제한다. | 마스크가 겹치는 값만 전달한다. 부모의 빈 경로를 정리하고 부모는 새 값을 발행할 수 있다. |
| G1 | 같은 필터·다른 필터를 같은 부모와 서로 다른 부모에 등록한다. | 같은 부모의 같은 필터 객체만 공유하고, 거짓이면 하위 전체를 건너뛴다. 형제가 많은 곳에서 빈 노드를 제거했다가 다시 등록하면 마지막 형제가 된다. |
| G2 | 필터와 Branch를 합쳐 깊이 256인 경로에서 추가 단계를 만든다. | 256단계까지 전파하고 257단계 경로 생성은 거부한다. |
| F1 | 연결된 스트림의 구독과 상위의 구독이 같은 값에서 실패한다. | 정상 수신자까지 순회한 뒤 처음의 미처리 예외를 값을 넣은 쪽에 전달한다. 실패한 두 구독을 해제하고 다음 값은 계속 전달한다. |
| F2 | SkipWhile·TakeWhile 조건이 예외를 던진다. | 그 스트림만 통지 없이 폐기하고 형제에게 값을 전달한다. 처리기가 없으면 순회 후 값을 넣은 쪽에 예외를 전달한다. |
| M1 | Merge에 폐기된 입력을 넘기거나, 입력을 하나씩 완료·폐기한다. | 폐기된 입력은 거부한다. 모든 입력이 완료하면 결과도 완료한다. 입력이 폐기되면 그 입력만 빠지고, 입력이 하나도 남지 않으면 통지 없이 폐기된다. |
| M2 | 같은 값이 Branch 두 개를 모두 통과한 뒤 Merge에 도달한다. | 입력마다 한 번씩 전달한다. |

## Branch 수명 상태 전이

부모의 루트에서 Branch를 만들고 Branch의 짝수 Filter에 두 명을 등록한다. U1과 U2는 Branch를 비활성화하는 단계까지 같은 이력을 갖는다.

| 경로 | 동작 | 관찰할 상태 |
| --- | --- | --- |
| 공통 | 두 명을 등록하고 2를 발행한다. | 두 구독자가 2를 받고 조건은 한 번 평가된다. 부모에는 Branch 연결 하나, Branch에는 공유 조건 하나가 있다. |
| 공통 | 첫 구독을 해제하고 3, 4를 발행한다. | 첫 구독은 2에서 끝나며 남은 구독은 4도 받는다. 누적 조건 평가 횟수는 3이다. |
| 공통 | Branch를 비활성화하고 부모에 6을 발행한다. | Branch 안의 조건 평가 횟수와 수신 목록은 그대로이다. |
| U1 | Branch를 다시 활성화하고 8을 발행한 뒤 마지막 구독을 해제한다. | 남은 구독자가 8을 받고 Branch와 부모 경로가 정리된다. 부모에 새로 구독하면 10을 받을 수 있고 조건은 누적 4회에서 멈춘다. |
| U2 | Branch가 비활성일 때 부모를 완료한다. | 남은 구독자만 완료를 한 번 받고 두 스트림이 폐기된다. 조건 평가 횟수는 3이다. |
