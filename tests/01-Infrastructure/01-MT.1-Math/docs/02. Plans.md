## 실행 구성

기존 UniEngine.Tests 프로젝트의 NUnit 3 직접 테스트를 사용한다. 본체는 .NET Standard 2.1·C# 9이고 테스트는 .NET 10·C# 9이다. [입력·동작 표](01.%20Tables.md)를 아래 테스트로 검증한다.

| 테스트 | 범위 |
| --- | --- |
| [UniMathTests](../UniMathTests.cs) | M1–M9, 비교·보정·방향·회전과 잘못된 입력 |
| [UniMathVectorTests](../UniMathVectorTests.cs) | M10–M13, 벡터 유한성·double 거리·보간·도 단위 방향 |

벡터 함수는 별도의 [VectorFunctions 계획](../../01-MT.2-VectorFunctions/docs/02.%20Plans.md)에서 관리한다.

## 검증 기준

- 명시적 기대값과 오차 경계의 안·밖을 검증한다. 새 구현의 계산식을 복제한 기대값을 사용하지 않는다.
- Vector4.IsZero 기본 호출, 0 오차 동등성, 작은 양수 스냅 단위, q와 -q, 작은 회전각을 회귀 사례로 포함한다.
- 회전 오차는 도 단위이며 0.000005도·0.00002도로 기본값 0.00001도의 안·밖을 확인한다. 180도 경계는 포함하고 그보다 작은 오차는 반회전 전체를 허용하지 않는다. System.Numerics 입력에서만 라디안으로 변환한다.
- float 제곱에서 오버플로·언더플로가 날 수 있는 입력을 포함하여 유한한 결과의 의미를 확인한다.
- 본체 Release 빌드로 System.Math 이름 충돌과 타깃 프레임워크 호환성을 확인한다.
- 벡터 공통화는 Math·VectorFunctions·Objects 비교와 GeoSystem 회귀를 함께 실행한다. 기존 GeoSystem의 LinearSegment·PolySegment·Shaper·Pin·Clip·Route 통합 및 독립 seed 0·1·2, 깊이 100의 연속 실행으로 소비자 동작을 확인한다. 본체·테스트·GeoSystem 샘플을 Release로 빌드하며 전체 회귀는 장시간 실행 확인 후 진행한다.
- 모듈 검증은 TestCategory=Math 필터로 실행한다. Infrastructure의 값 형식이 UniMath를 사용하는 공개 API 변경은 [Objects 계획](../../02-O.1-Objects/docs/02.%20Plans.md)의 비교 계약과 함께 검증하고, 장시간 실행 확인을 받은 뒤 일반 전체 테스트를 실행한다.
- 별도 벤치마크·Unity 실행·Project-Index 테스트는 범위에 포함하지 않는다. 실행 결과와 미실행 항목은 [결과 기록](03.%20Results.md)에 구분한다.

## 실행 명령

저장소 루트에서 실행한다. 아래 명령은 기존 복원 결과를 사용하며 의존성이 없으면 먼저 dotnet restore를 수행한다.

```powershell
dotnet build src/UniEngine.sln -c Release --no-restore
dotnet test tests/UniEngine.Tests.csproj -c Release --no-restore --filter 'TestCategory=Math' --logger 'trx;LogFileName=Math.trx' --results-directory tests/bin/TestResults/InfrastructureMathematics
```

벡터 공통화의 관련 회귀는 다음 필터로 실행한다.

```powershell
dotnet test tests/UniEngine.Tests.csproj -c Release --no-build --no-restore --filter 'TestCategory=Math|TestCategory=VectorFunctions|TestCategory=GeoSystem|FullyQualifiedName~InfrastructureObjectTests|FullyQualifiedName~TransformComparisonTests|FullyQualifiedName~IntegerVectorComparisonTests' --logger 'trx;LogFileName=Focused.trx' --results-directory tests/bin/TestResults/UniMathVectors20261118
```
