## 확인한 계약

- 실수·벡터 오차 경계와 오차 0, Vector4.IsZero 기본 호출, 비유한 피연산자와 잘못된 허용 오차를 확인했다.
- 기존 tolerant 부호·대소 경계, 짝수 배수 반올림, 작은 양수 스냅 단위와 SnapTo 반환 계약을 확인했다.
- 매우 크거나 작은 벡터의 거리·방향 판정, 부호·크기가 다른 쿼터니언의 동등성, 작은 라디안 각도·90도·180도 관계를 확인했다.
- 직선·베지어의 알려진 좌표와 외삽, 가변 프로퍼티 반영, 정규화 실패 시 상태 보존을 확인했다.

## 실패와 제한

최초 샌드박스 실행은 VSTest가 90초 안에 testhost에 연결하지 못해 테스트 시작 전에 중단됐다. [중단 기록](../../../bin/TestResults/MathMigration/MathSandboxAborted.trx)은 성공 실행과 별도로 보존한다. 샌드박스 밖에서 같은 Math 범위를 실행하여 통과했으며 중단 시도를 통과 수에 포함하지 않았다.

검증 범위는 Release 빌드와 Math 모듈로 한정했다. 기존 모듈은 신규 Math API를 소비하지 않고, EventStream의 System.Math.Max 형식 이름 명시는 동작을 변경하지 않아 빌드로 확인했다. 일반 전체 테스트, Unity 실행, Project-Index 테스트와 별도 벤치마크는 이번 검증 범위에 포함하지 않는다.
