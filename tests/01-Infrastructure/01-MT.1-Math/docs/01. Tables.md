# Math 입력·동작 표

## 목차

- 검증 대상
- 입력과 기대 동작

## 검증 대상

UniMath는 무상태 수학 계산 도구이다. 순수 계산의 입력·결과·실패 계약을 NUnit 직접 사례로 검증한다. UniTest 랜덤 상태 전이 프로젝트는 추가하지 않는다.

## 입력과 기대 동작

| ID | 입력·상태 | 동작 | 기대 결과 |
| --- | --- | --- | --- |
| M1 | 유한한 실수, 오차 안·경계·밖·0 | Is·IsZero | 절대 차이가 오차 이하면 참 |
| M2 | 부호·대소 경계 양쪽, tolerant 양쪽 | 부호·대소 비교 | 기존 strict/inclusive 경계식 유지 |
| M3 | NaN·양/음 무한대, 음수·비유한 오차 | 일반 비교 | 비유한 피연산자는 거짓, 잘못된 오차는 인자 예외 |
| M4 | Vector2·3·4, 대각 성분·큰 값·최소 양수 | Is·IsZero | 유클리드 거리 판정, 제곱 오버플로·언더플로 방지 |
| M5 | 양수·음수·중간값, 양수 단위·작은 단위 | Snap | 짝수 배수 반올림, 성분별 보정, 잘못된 단위는 예외 |
| M6 | 기준값의 오차 경계·밖·비유한 값 | SnapTo | 기준값/true 또는 원래 값/false |
| M7 | 동일·반대·비평행 방향, 크기 차이·영벡터 | IsParallelWith | 방향 관계 판정, 정의할 수 없는 방향은 예외 |
| M8 | 같은 회전·부호 반전·배수·비단위·영쿼터니언 | IsSameRotationAs | 정규화된 회전 동등성, 잘못된 회전은 예외 |
| M9 | 90도·180도·작은 각도·각도 경계 | 두 회전 판정 | 도 단위 허용 오차, 기본값 0.00001도, 같은 회전과 반회전 구분 |
