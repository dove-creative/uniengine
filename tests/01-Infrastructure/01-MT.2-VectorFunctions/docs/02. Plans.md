# VectorFunctions 테스트 계획

## 실행 구성

기존 UniEngine.Tests 프로젝트의 [VectorFunctionTests](../VectorFunctionTests.cs)가 [입력·동작 표](01.%20Tables.md)의 V1–V3을 검증한다. 본체는 .NET Standard 2.1·C# 9이고 테스트는 .NET 10·C# 9이다.

## 검증 기준

- 직선·베지어의 알려진 좌표와 외삽, 가변 프로퍼티의 다음 평가 반영을 확인한다.
- 큰 방향·작은 방향의 정규화와 영벡터·비유한 방향 실패 시 상태 보존을 확인한다.
- 순수 계산과 값 변경 계약이므로 UniTest 상태 전이 프로젝트를 추가하지 않는다.
- 네임스페이스 등 공개 API 변경은 모듈 검증 후 장시간 실행 확인을 받은 뒤 일반 전체 테스트로 검증한다.

## 실행 명령

```powershell
dotnet test tests/UniEngine.Tests.csproj -c Release --no-restore --filter 'TestCategory=VectorFunctions' --logger 'trx;LogFileName=VectorFunctions.trx' --results-directory tests/bin/TestResults/InfrastructureMathematics
```
