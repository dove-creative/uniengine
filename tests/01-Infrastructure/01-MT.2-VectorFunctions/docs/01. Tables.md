# VectorFunctions 입력·동작 표

## 검증 대상

AffineLine·QuadraticBezier의 매개변수 평가, 프로퍼티 변경과 정규화 실패 시 상태 보존을 NUnit 직접 사례로 검증한다.

## 입력과 기대 동작

| ID | 입력·상태 | 동작 | 기대 결과 |
| --- | --- | --- | --- |
| V1 | 직선의 t = 0·0.5·1·-1·2 | Evaluate | 알려진 좌표와 외삽 값 |
| V2 | 방향 변경·작은/큰 방향·유효하지 않은 방향 | Normalize | 단위 방향 또는 예외와 상태 보존 |
| V3 | 베지어의 끝점·중간점·외삽·제어점 변경 | Evaluate | 알려진 곡선 좌표와 다음 평가에 변경 반영 |
