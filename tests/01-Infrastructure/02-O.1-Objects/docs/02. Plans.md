# Infrastructure Objects 테스트 계획

## 목차

- 실행 구성
- 검증 기준

## 실행 구성

단일 UniEngine.Tests 프로젝트의 InfrastructureObjectTests가 O1–O4, TransformComparisonTests가 O5–O7, IntegerVectorComparisonTests가 O7–O8을 검증한다. 테스트는 공개 API를 호출하고 내부 구현에 직접 접근하지 않는다.

## 검증 기준

- 각 값 형식의 생성·복사와 동등성·해시 계약을 구분하여 검사한다.
- Transform은 위치와 회전의 각 성분을 개별 변경하여 비교 누락을 검출한다.
- 문화권 사례는 병렬 실행을 막고 finally에서 원래 CurrentCulture를 복원한다.
- 해시 값 자체나 Dictionary의 내부 배치는 고정하지 않는다.
- Is의 기본 거리 오차는 UniMath.Epsilon, 기본 회전 오차는 UniMath.AngularEpsilon = 0.00001도이다. 위치·회전 오차를 별도로 바꿔 비교 누락을 검출하고, 360도 주기·180도 경계·q와 -q·최소 양수·최댓값도 포함한다. 2D·3D에서 0.000005도·0.00002도로 기본 회전 오차의 안·밖을 확인한다.
- 정수 벡터는 3·4·5 및 3·4·12·13 거리 경계와 int 극값의 인접 좌표를 사용해 알려진 기대값을 확인한다.
- 관련 모듈 검증 후 장시간 실행 확인을 받은 뒤 일반 전체 테스트를 실행한다. Unity와 별도 벤치마크는 범위에 포함하지 않는다.

## 실행 명령

```powershell
dotnet test tests/UniEngine.Tests.csproj -c Release --no-restore --filter 'TestCategory=Math|TestCategory=VectorFunctions|FullyQualifiedName~InfrastructureObjectTests|FullyQualifiedName~TransformComparisonTests|FullyQualifiedName~IntegerVectorComparisonTests' --logger 'trx;LogFileName=FocusedFinal.trx' --results-directory tests/bin/TestResults/InfrastructureMathematics

dotnet test tests/UniEngine.Tests.csproj -c Release --no-build --no-restore --logger 'trx;LogFileName=Full.trx' --results-directory tests/bin/TestResults/InfrastructureMathematics
```
