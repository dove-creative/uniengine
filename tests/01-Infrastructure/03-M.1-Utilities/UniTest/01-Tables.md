# 표시 유틸리티 상태와 동작

## 목차

1. 범위
2. 검증 계약

## 범위

DataFormattingExtensions의 공개 표시 계약을 NUnit 직접 테스트로 검증한다. JSON 변환 테스트와 결과는 Json/UniTest에서 관리한다.

## 검증 계약

| ID | 상태·동작 | 기대 결과 |
| --- | --- | --- |
| F1 | 정수·실수의 축약 표시 | K·M 경계, 반올림, 음수와 정수 범위를 일관되게 표시한다. NaN·양/음의 무한대는 보존한다. |
| F2 | 시간 표시 | 초·분·총 시간 경계와 음수 부호를 표시한다. TimeSpan 양 끝에서도 분 성분을 잃지 않는다. |
| F3 | 문화권 독립 표시 | 숫자·쿼터니언·Transform·컬렉션 표시가 CurrentCulture에 따라 바뀌지 않는다. |
| F4 | null·빈 컬렉션·간단/상세 표시 | null과 빈 목록을 구분하고 순서·개수·인덱스·구분선을 표시한다. |
| F5 | 선택 함수와 일반 객체 | 선택 함수를 각 항목에 한 번 적용하며 null·IFormattable·사용자 ToString 결과를 표현한다. |
| F6 | 지연 열거와 실패 | 목록이 아닌 입력은 한 번만 열거하며 열거·선택 함수 예외를 원래 인스턴스로 전달한다. |
