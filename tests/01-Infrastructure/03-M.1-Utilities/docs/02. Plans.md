# 표시 유틸리티 테스트 계획

## 목차

- 실행 구성
- 검증 기준
- 실행과 기록

## 실행 구성

단일 UniEngine.Tests 프로젝트의 DataFormattingExtensionsTests가 F1–F6을 검증한다. 순수 입력·출력 계약이므로 UniTest 상태 전이 프로젝트는 추가하지 않는다.

## 검증 기준

- K·M 임계값 전후와 TimeSpan 초·분·시간 경계에 명시적인 기대 문자열을 사용한다.
- TimeSpan.MaxValue·MinValue는 총 시간과 분 나머지의 범위 초과를 검출한다.
- 매우 큰 양·음수 시간에서 시간 경계보다 1틱 작은 값은 다음 시간으로 반올림하지 않는다.
- 문화권 변경은 병렬 실행을 막고 finally에서 원래 CurrentCulture를 복원한다.
- 줄 구분은 Environment.NewLine을 사용하여 운영체제에 맞춘다.
- 한 번만 열거할 수 있는 소스와 실패하는 소스를 사용하여 열거 횟수·예외 전달을 확인한다.
- 실제 계약 실패는 테스트를 숨기거나 기대값을 변경하지 않고 결과에 남긴다.

## 실행과 기록

저장소 루트에서 .NET 10 SDK로 모듈을 실행한다. 전체 실행과 정적 상태 격리 절차는 [통합 테스트 계획](../../docs/02.%20Plans.md)을 따른다.

```powershell
dotnet test tests/UniEngine.Tests.csproj -c Release --no-restore --filter 'FullyQualifiedName~DataFormattingExtensionsTests' --logger 'trx;LogFileName=Infrastructure-Formatting-Fix.trx' --results-directory tests/bin/TestResults
```

재검증은 실행별 결과 이름을 사용하여 이전 원본을 보존한다. [검증 결과](03.%20Results.md)에 입력·기대 문자열·실제 문자열, 실행 범위와 통과·실패·건너뜀을 기록한다. 모듈만 재실행했다면 전체 결과와 구분한다.
