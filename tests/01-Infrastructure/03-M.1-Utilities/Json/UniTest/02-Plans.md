# JSON 변환 테스트 계획

## 목차

1. 실행 구성
2. 검증 기준

## 실행 구성

기존 단일 GoldenHind.Tests 프로젝트와 NUnit 실행기를 사용한다. 개별 입력과 결과만으로 표현되는 계약이므로 UniTest 상태 전이 프로젝트는 추가하지 않는다.

| 테스트 파일 | 표의 범위 | 구현 방향 |
| --- | --- | --- |
| JsonConverterTests.cs | J1–J5 | 공개 JsonSerializer와 등록 확장을 사용한다. 8개 형식의 고정 기대 JSON, 순서·대소문자 변경, 모든 최상위 성분의 누락·중복·잘못된 타입과 숫자 경계를 매개변수 사례로 검증한다. |
| JsonSerializerOptionsExtensionsTests.cs | J6–J7 | 옵션 반환값·변환기 인스턴스 유지와 실제 사용자 변환기 호출, Transform 내부 변환 경로를 검증한다. |

## 검증 기준

- 테스트 코드는 C# 9와 LF를 사용한다. 본체는 기존 프로젝트를 참조하며 제품 코드를 수정하지 않는다.
- Color 동등성은 이름이나 생성 상태 대신 ARGB 성분을 비교한다. 임의 실수의 양자화 결과와 byte 왕복은 구분한다.
- NaN·무한대 쓰기와 유한 float 범위를 넘는 JSON 숫자 읽기를 모두 검증한다. 정수 형식에는 소수와 Int32 양쪽 범위 초과 입력을 사용한다.
- 잘못된 결과에 맞추어 단언을 약화하지 않는다. 실패한 계약은 결과 문서에 재현 조건과 함께 기록한다.
- 전체 통합 검증은 루트 작업에서 수행하고 JSON 범위 결과도 기록한다.
