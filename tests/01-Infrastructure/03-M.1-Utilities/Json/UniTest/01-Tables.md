# JSON 변환 상태와 동작

## 목차

1. 범위

## 범위

공개 JSON 등록 확장과 8개 값 형식의 직렬화·역직렬화 계약을 검증한다. 내부 JsonComponentSerializer는 공개 변환기를 통해 간접 검증한다.

| ID | 상태·동작 | 기대 결과 |
| --- | --- | --- |
| J1 | Vector2·Vector3·Vector2Int·Vector3Int·Quaternion·Color·Transform2D·Transform3D 저장과 복원 | 선언된 성분 구조로 저장하며 원래 값을 복원한다. 회전은 자동 정규화하지 않는다. |
| J2 | 속성 순서 변경과 대소문자 혼합 | 중첩 성분을 포함하여 같은 값으로 복원한다. |
| J3 | 루트 타입 오류·성분 누락·대소문자만 다른 중복·미지원 속성·잘못된 성분 타입·불완전 객체 | JsonException으로 거부한다. |
| J4 | Int32 경계·소수·초과 값과 float 경계·비유한 값 | 정수 경계와 유한 float 양쪽 경계·최소 양수는 유지하고 범위 초과·소수 정수·비유한 숫자는 읽기·쓰기에서 거부한다. |
| J5 | Color 정규화·양자화·성분별 범위 오류 | byte 성분을 0~1로 저장하고 임의 실수는 byte 정밀도로 반올림하며 범위 밖 성분은 거부한다. |
| J6 | 변환기 최초·반복 등록과 null 옵션 | 같은 옵션을 반환하고 8개 변환기를 한 번씩 등록하며 null을 거부한다. |
| J7 | 사용자 변환기가 있는 옵션 등록 | 해당 형식의 기존 변환기 인스턴스·위치·실제 동작을 보존한다. Transform 내부 성분은 자체 변환기를 사용한다. |
