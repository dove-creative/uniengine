## DataPath 조회 검증

2026-11-15 DataPath 공개 API와 lock 없는 경로 조회를 적용한 Release 빌드는 경고·오류 0개이며, 전체 일반 테스트는 1,278개 통과·실패 0개·건너뜀 0개이다. 실행 시간은 약 1분 6초이다. Configuration의 직접 사례 9개와 기존 UniTest 사례 4개, Bootstrapper 사례 17개가 전체 실행에 포함됐다.

ConcurrentReaders는 네 스레드가 초기화 전 조회를 거부하고, 초기화와 동시에 조회한 뒤 두 경로가 함께 준비되어 변경되지 않는 것을 확인했다. 경로를 담는 변경 불가능한 객체 하나를 volatile 참조로 공개하고 getter에는 lock이 없는 것도 소스에서 확인했다. Log와 테스트 지원 코드, 문서의 DataPath 참조 및 실제 데이터 저장 위치 유지도 검증했다.
