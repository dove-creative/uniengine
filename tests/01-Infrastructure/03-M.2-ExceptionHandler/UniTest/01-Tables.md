# ExceptionHandler 상태와 동작

## 목차

1. 범위

## 범위

공개 Report·SetHandler·SafeInvoke의 예외 처리 계약을 검증한다. 내부 필드에 접근하거나 테스트용 초기화 기능을 제품 코드에 추가하지 않는다.

| ID | 상태·동작 | 기대 결과 |
| --- | --- | --- |
| E1 | null 예외 보고 | 처리기를 호출하지 않고 ArgumentNullException을 던진다. |
| E2 | 처리기 등록 상태의 보고 | 원래 예외 인스턴스를 처리기에 전달한다. |
| E3 | 처리기가 없는 보고 | 같은 예외를 원래 throw 위치를 보존하여 재전파한다. |
| E4 | 처리기 자체의 실패 | 처리기가 던진 예외를 그대로 전파한다. |
| E5 | 인자 0~4개의 null·정상 다중 호출 | null은 무시하며 모든 인자와 호출 순서를 유지한다. |
| E6 | 처리된 구독자 실패와 반복 호출 | 후속 구독자를 호출하고 실패한 구독자도 다음 호출에 유지한다. |
| E7 | 미처리·처리기 실패의 구독자 호출 | 예외를 전파하고 후속 구독자를 호출하지 않는다. |
| EU1 | 등록 → 교체 → 해제 | 첫 처리기·교체 처리기·재전파 정책으로 순서대로 전환한다. |
