# ExceptionHandler 검증 결과

## 목차

1. 실행 결과
2. 확인한 범위

## 실행 결과

2026-11-02의 .NET SDK 10.0.403 Release 통합 실행에서 ExceptionHandler 사례 30개가 모두 통과하였다. 실패·건너뜀은 없다.

| 검증 | 결과 |
| --- | --- |
| NUnit 직접 사례 | 29개 통과 |
| UniTest 등록 → 교체 → 해제 | 1개 통과 |

UniTest의 전체 성공·취소 없음·최종 실행 횟수 3을 확인하였다. ExceptionHandler 범위에서 제품 결함은 발견되지 않았다. 전체 저장소의 실행 결과와 정적 상태 재실행 결과는 [Infrastructure 테스트](../../README.md)를 따른다.

## 확인한 범위

NUnit은 null 보고 거부, 예외 인스턴스와 원래 throw 위치 보존, 처리기 실패 전파를 검증하였다. SafeInvoke의 인자 0~4개 오버로드 모두에서 null·정상 다중 호출·인자 전달·처리 후 계속·미처리 중단·처리기 실패 중단을 확인하였다. 처리된 실패 구독자는 반복 호출에도 유지된다.

제품 동작은 변경하지 않았다. 정적 처리기는 각 사례 전후에 해제하며 병렬 실행하지 않는다. 테스트 코드와 문서는 UTF-8·LF이다.
