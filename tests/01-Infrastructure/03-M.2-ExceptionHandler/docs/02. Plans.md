# ExceptionHandler 테스트 계획

## 목차

- 실행 구성
- 검증 기준

## 실행 구성

기존 UniEngine.Tests 프로젝트에서 [ExceptionHandlerTests](../ExceptionHandlerTests.cs)의 NUnit 개별 사례를 주 검증으로 실행한다. UniTest 폴더의 [ExceptionHandlerStateProjectTests](../UniTest/ExceptionHandlerStateProjectTests.cs)는 UniTest CompactProject의 Inline 실행으로 등록 → 교체 → 해제 흐름을 검증한다. 표·계획·결과는 이 docs 폴더에서 관리하며 모든 검증은 제품의 공개 API를 사용한다.

## 검증 기준

- 두 테스트 클래스에 NonParallelizable을 지정하고 각 사례의 SetUp·TearDown에서 처리기를 해제한다.
- SafeInvoke의 인자 0~4개 오버로드 모두에서 null·정상 호출·처리 후 계속·미처리 중단·처리기 실패 중단을 검증한다.
- 예외 동일성과 원래 throw 메서드 포함 여부를 검증하며 전체 스택 문자열은 비교하지 않는다.
- UniTest의 전체 성공·취소 여부와 최종 실행 횟수 3을 확인하고 실패 메시지에 JSON 보고서를 포함한다.
- 전체 테스트 실행 후 정적 상태 관련 사례를 별도로 재실행한다. 제품 결함이 드러나면 기대값을 완화하지 않고 결과에 기록한다.
