| IntegerVectorComparisonTests | 7 | 0 |

[FocusedFinal.trx](../../bin/TestResults/InfrastructureMathematics/FocusedFinal.trx)는 이 표의 단일 실행 원본이다. 종료 코드는 0, NUnit의 사례 실행 시간 표시는 99ms, TRX의 실행 시작부터 종료까지는 약 2.49초이다. 빌드 시간은 이 구간과 구분한다.

앞선 [Focused.trx](../../bin/TestResults/InfrastructureMathematics/Focused.trx)는 정수 벡터 Is 추가 전 103개가 통과한 실행이며 위 합계에 더하지 않는다. 각 모듈의 입력·실패 계약과 범위는 [Math 계획](../01-MT.1-Math/docs/02.%20Plans.md), [VectorFunctions 계획](../01-MT.2-VectorFunctions/docs/02.%20Plans.md), [Objects 계획](../02-O.1-Objects/docs/02.%20Plans.md)을 따른다.

사용자가 관련 테스트 범위까지만 확인하도록 지정하여 일반 전체 테스트는 실행하지 않았다. Unity 실행과 별도 벤치마크도 수행하지 않았다. 다른 모듈의 전체 회귀 결과로 해석하지 않는다.
