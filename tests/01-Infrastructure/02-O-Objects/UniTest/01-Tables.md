# Infrastructure Objects 상태와 동작

## 목차

1. 범위
2. 검증 계약

## 범위

Vector2Int·Vector3Int·Transform2D·Transform3D의 공개 값 계약을 검증한다. 상태 전이 프로젝트 없이 NUnit 직접 테스트를 사용한다.

## 검증 계약

| ID | 상태·동작 | 기대 결과 |
| --- | --- | --- |
| O1 | 생성·기본값·Zero·Identity | 지정 성분을 보존하고 형식별 기준값을 제공한다. 기본 Transform3D의 영 쿼터니언은 Identity와 구분한다. |
| O2 | 복사 후 성분 변경 | 복사본의 위치·회전·좌표 변경이 원본에 영향을 주지 않는다. 각도·쿼터니언을 정규화하지 않는다. |
| O3 | 동등성·연산자·해시 키 | 모든 성분으로 동등성을 판정하고 같은 값은 같은 해시를 제공한다. null·다른 형식과 같지 않다. |
| O4 | 문화권 변경 후 문자열 표시 | 프랑스어·터키어 문화권에서도 동일한 숫자와 성분 표현을 제공한다. |

해시는 같은 값의 일관성만 검증한다. 서로 다른 값의 해시가 반드시 달라야 한다는 보장은 요구하지 않는다.
