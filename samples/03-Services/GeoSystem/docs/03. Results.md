# GeoSystem 시각화 예제 검증 결과

## 2026-11-16

[검증 계획](02.%20Plans.md)에 따라 Windows·.NET 10에서 확인했다.

| 검증 | 결과 |
| --- | --- |
| 시각화 예제 Release 빌드 | 통과, 경고 0·오류 0. 최종 산출물은 `bin/Verified`에서 확인. |
| `help` | 사용 방법 출력, 종료 코드 0 |
| `verify` | POCO 시나리오 17개 조건 통과, 종료 코드 0 |
| 알 수 없는 명령 | 사용 방법 안내, 종료 코드 1 |
| 기존 콘솔 예제 Release 빌드 | 통과, 경고 0·오류 0 |
| 기존 `event-stream` 실행 | 예상한 이벤트 순서·분기·병합·병렬 결과 출력, 종료 코드 0 |
| 전체 회귀 테스트 | 1,496개 모두 통과. 실패·오류·건너뜀 0개, 종료 코드 0. 약 12분 6초 소요. |
| 수동 GUI 검증 | 사용자 요청으로 보류. 실제 창 배치와 마우스·키보드 조작은 검증하지 않음. |

창 없는 검증은 화면 렌더링·입력 이벤트 배선의 성공을 보장하지 않는다. Linux·macOS 실행은 확인하지 않았다.

첫 샌드박스 실행은 문서 폴더의 Configuration 디렉터리 생성 권한이 없어 실패했다. 일반 사용자 권한으로 다시 실행한 시나리오 검증은 통과했다. 전체 회귀의 원본 기록은 `tests/bin/GeoSystem/demo-full.trx`와 `tests/bin/GeoSystem/demo-full-progress.log`에 둔다. 이 기록은 무시된 빌드 산출물이며 소스 배포에 포함하지 않는다.

최종 빌드 시 기존 `bin/Release/net10.0`의 실행 파일이 잠겨 복사가 실패했다. PC 조작 보류 요청에 따라 창이나 프로세스를 조작하지 않고 아래 명령으로 별도 출력 폴더에 빌드했다. 이 최종 DLL에서 `help`·`verify`·알 수 없는 명령의 결과를 다시 확인했다.

```powershell
dotnet build samples/03-Services/GeoSystem/UniEngine.GeoSystem.Sample.csproj -c Release --no-restore -o samples/03-Services/GeoSystem/bin/Verified
dotnet samples/03-Services/GeoSystem/bin/Verified/UniEngine.GeoSystem.Sample.dll verify
```
