# GeoSystem 시각화 예제 검증 계획

## 범위

독립 예제 프로젝트의 빌드·명령 진입점과 UI에 연결되는 실제 POCO 시나리오를 검증한다. 본체의 연결·수학·폐기 계약은 기존 전체 회귀 테스트로 함께 확인한다. GUI 검증은 별도 단계로 구분한다.

## 자동 검증

명령은 저장소 최상위에서 실행한다.

```powershell
dotnet build samples/03-Services/GeoSystem/UniEngine.GeoSystem.Sample.csproj -c Release
dotnet run --project samples/03-Services/GeoSystem/UniEngine.GeoSystem.Sample.csproj -c Release --no-build -- help
dotnet run --project samples/03-Services/GeoSystem/UniEngine.GeoSystem.Sample.csproj -c Release --no-build -- verify
dotnet run --project samples/03-Services/GeoSystem/UniEngine.GeoSystem.Sample.csproj -c Release --no-build -- unknown-command
dotnet build samples/UniEngine.Samples.csproj -c Release
dotnet run --project samples/UniEngine.Samples.csproj -c Release --no-build -- event-stream
dotnet test tests/UniEngine.Tests.csproj -c Release --no-restore
```

`help`와 `verify`는 종료 코드 0, 알 수 없는 명령은 종료 코드 1을 기대한다. `verify`의 17개 조건은 다음과 같다.

| 범위 | 조건 수 | 기대 결과 |
| --- | --- | --- |
| 초기화 | 3 | 노드 4개·구간 3개, 유효한 정방향 Clip, 원본 길이의 60% |
| 변경 전파 | 2 | B 이동 후 Route 길이 증가, 엔진 변경 알림 기록 |
| Clip | 3 | 핀 순서 변경 시 반전, 겹치면 무효화, 분리하면 복구 |
| 앵커·방향 | 3 | 정방향 원점 A, 역방향 원점 D, Hold가 Traveller 추종 |
| 재생·조회 | 3 | 시간에 따른 전진, 정지 후 위치 보존, Route의 변환 조회 성공 |
| 초기화·폐기 | 3 | 초기화 시 기존 그래프 폐기, 기본 설정 복원, 장면 폐기 시 소유 객체 폐기 |

기존 콘솔 프로젝트는 GUI 소스와 UI 패키지를 포함하지 않아야 하며, EventStream 대표 시나리오가 정상 종료해야 한다. 전체 회귀는 실행 시간이 길므로 AGENTS.md에 따라 먼저 사용자에게 확인한다.

## 수동 GUI 검증

일반 크기와 최소 크기 창에서 텍스트·그래프·조절 패널이 보이는지 확인한다. 노드 드래그, 휠, 가운데 버튼 이동, 전체 보기, 진행·속도·Clip 슬라이더, 역방향 조회, 재생·정지, 초기화와 닫기를 조작한다. 화면의 좌표·길이·회전과 실제 객체 변화가 일치해야 한다.
