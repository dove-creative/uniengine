# Hierarchy

## Dependency Direction

UniEngine의 계층은 역할과 의존 관계에 따라 구분한다.

계층별 폴더와 객체 설명은 [UniEngine 구현 문서](../02.%20UniEngine/README.md)에서 확인한다. 구현이 없는 항목은 각 문서에 설계 단계로 표시한다.

각 계층은 상위 계층에 의존하며, 하위 계층은 상위 계층을 기반으로 구성된다.

0. Foundations
1. Infrastructure
2. UniEngine Core
3. Services

## 0. Foundations

UniEngine과 그 하위 계층의 개발·검증·운영을 지원하는 외부 보조 프레임워크 계층이다.

- [Blackbox System](https://github.com/dove-creative/blackbox-system): 흐름 추적 장치
- [UniTest](https://github.com/dove-creative/unitest): 유닛 테스트 프레임워크

UniEngine에서의 역할과 연결은 [보조 프레임워크 문서](../02.%20UniEngine/00-Foundations/README.md)에 정리한다.

두 프레임워크는 독립 저장소에서 개발한다. UniEngine 본체는 Blackbox System을, 테스트는 UniTest를 컴파일된 NuGet 패키지로 참조하며 본체에는 테스트 의존성을 추가하지 않는다. 두 자사 패키지는 저장소의 `packages`에 보관하며, [패키지 문서](../../packages/README.md)에 버전·원본 커밋·SHA-256과 갱신 절차를 기록한다.

## 2. UniEngine Core

UniEngine의 기반 기능 계층이다.

객체 제어, 이벤트 전파, 데이터 표현, 공통 계약 등 하위 계층이 공통으로 의존하는 핵심 기능을 제공한다.

층별 객체 색인과 Event System의 구성·협력 흐름은 [Core 구성](../02.%20UniEngine/02-Core/README.md)에 있다. 전파·실패·폐기의 세부 규칙은 각 모듈 문서를 따른다.

| Event System                                       | Objects                                                                             | Bootstrapper |
| -------------------------------------------------- | ----------------------------------------------------------------------------------- | ------------ |
|                                                    | Utilities<br>IInitializable<br>IAcquirable<br>IEnumerationSource<br>ValueEnumerator |              |
| Handle/Token<br>AdaptiveCollections<br>EventStream | Property                                                                            |              |
| LifecycleHub<br>EventHub                           |                                                                                     |              |
|                                                    |                                                                                     | Bootstrapper |


### Level 1

- [Utilities](../02.%20UniEngine/02-Core/01-O.1-Utilities/README.md): 비트 연산과 참조형 토큰 비교
- [IInitializable](../02.%20UniEngine/02-Core/01-O.2-Interfaces/IInitializable.md): 초기화가 필요한 객체 계약
- [IAcquirable](../02.%20UniEngine/02-Core/01-O.2-Interfaces/IAcquirable.md): 자신을 제어할 수 있는 단일 프록시 제공 객체 계약
- [IEnumerationSource](../02.%20UniEngine/02-Core/01-O.2-Interfaces/IEnumerationSource.md): 순회의 시작·이동·종료와 식별자를 제공하는 공통 계약
- [ValueEnumerator](../02.%20UniEngine/02-Core/01-O.3-Objects/ValueEnumerator.md): 순회 소스 계약을 사용하는 재사용 가능한 구조체 열거자

Core의 `01-O.2-Interfaces`에 순회 계약을 두고, 그 다음 `01-O.3-Objects`에 ValueEnumerator를 둔다. Objects는 Interfaces에 의존하며, AdaptiveCollection은 계약을 구현하고 구조체 열거자를 반환한다.

### Level 2

- [Handle/Token](../02.%20UniEngine/02-Core/02-E.1-HandleToken/README.md): `Dispose` 시 저장된 이벤트를 발행하는 객체
- [AdaptiveCollections](../02.%20UniEngine/02-Core/02-E.2-AdaptiveCollections/README.md): 순회 중 수정이 가능한 컬렉션
- [EventStream](../02.%20UniEngine/02-Core/02-E.3-EventStream/README.md): Rx 방식 이벤트 전파 시스템과 기본 틱 스트림 `EventStream.Main`

- [Property](../02.%20UniEngine/02-Core/02-O.1-Property/Property.md): 외부 페이로드 저장 장치

### Level 3

- [LifecycleHub](../02.%20UniEngine/02-Core/03-E.1-LifecycleHub/README.md): 객체별 연결과 폐기 완료 알림을 관리하는 시스템
- [EventHub](../02.%20UniEngine/02-Core/03-E.2-EventHub/README.md): 내부 EventStream으로 갱신 이벤트를 전달하며 객체별 연결과 생애주기를 관리하는 시스템

### Level 4

- [Bootstrapper](../02.%20UniEngine/02-Core/04-Bootstrapper/README.md): 공통 환경과 애플리케이션의 초기화 순서·상태·실패 정리 관리

## 3. Services

UniEngine을 기반으로 구축된 서비스 프레임워크 계층이다.
각 서비스는 특정 문제 영역을 해결하기 위한 응용 프레임워크이며, UniEngine의 공통 기능을 조합하여 사용한다.

- [StateMachines.Usm](../02.%20UniEngine/03-Services/StateMachines/Usm/README.md): 상태 기계 (Unified State Machine, FSM + BT)
- [StateMachines.Scp](../02.%20UniEngine/03-Services/StateMachines/Scp/README.md): 클립 기반 재생기 (Sequence Clip Player, 페트리넷형 상태 기계)
- [GeoSystem](../02.%20UniEngine/03-Services/GeoSystem/README.md): 그래프 모델링 시스템
- [MEP](../02.%20UniEngine/03-Services/MEP.md): Mesh 편집 패키지 (Mesh Extension Package)
