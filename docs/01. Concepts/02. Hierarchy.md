# Hierarchy

## Dependency Direction

UniEngine의 계층은 역할과 의존 관계에 따라 구분한다.

계층별 폴더와 객체 설명은 [UniEngine 구현 문서](../02.%20UniEngine/README.md)에서 확인한다. 구현이 없는 항목은 각 문서에 설계 단계로 표시한다.

각 계층은 상위 계층에 의존하며, 하위 계층은 상위 계층을 기반으로 구성된다.

0. Supportive Frameworks
1. Infrastructure
2. UniEngine Core
3. UniEngine Surface
4. Services

## 0. Supportive Frameworks

UniEngine과 그 하위 계층의 개발·검증·운영을 지원하는 외부 보조 프레임워크 계층이다.

- [Blackbox System](https://github.com/dove-creative/blackbox-system): 흐름 추적 장치
- [UniTest](https://github.com/dove-creative/unitest): 유닛 테스트 프레임워크

Golden Hind에서의 역할과 연결은 [보조 프레임워크 문서](../02.%20UniEngine/00-SupportiveFrameworks/README.md)에 정리한다.

두 프레임워크는 독립 저장소에서 개발한다. Golden Hind 본체는 Blackbox System을, 테스트는 UniTest를 컴파일된 NuGet 패키지로 참조하며 본체에는 테스트 의존성을 추가하지 않는다. 두 자사 패키지는 저장소의 `packages`에 보관하며, [패키지 문서](../../packages/README.md)에 버전·원본 커밋·SHA-256과 갱신 절차를 기록한다.

## 2. UniEngine Core

UniEngine의 기반 기능 계층이다.

객체 제어, 이벤트 전파, 데이터 표현, 공통 계약 등 하위 계층이 공통으로 의존하는 핵심 기능을 제공한다.

층별 객체 색인은 [Core 구성](../02.%20UniEngine/02-Core/README.md)에 있다. Event System의 구성과 공통 정책은 [Event System 개요](../02.%20UniEngine/02-Core/EventSystem.md)를 따른다.

| Event System                                       | Objects                                                                             | Utilities                                                                                      |
| -------------------------------------------------- | ----------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
|                                                    | Utilities<br>IInitializable<br>IAcquirable<br>IEnumerationSource<br>ValueEnumerator |                                                                                                |
| Handle/Token<br>AdaptiveCollections<br>EventStream | Property                                                                            | Math.VectorFunctions<br>Math.CompareValue<br>Utilities.DataComposer<br>Utilities.DataFormatter |
| EventHub                                           |                                                                                     | Utilities.TransformDataExtensions<br>Loco                                                      |

### Level 1

- [Utilities](../02.%20UniEngine/02-Core/01-O.1-Utilities/README.md): 비트 연산과 참조형 토큰 비교
- [IInitializable](../02.%20UniEngine/02-Core/01-O.2-Interfaces/IInitializable.md): 초기화가 필요한 객체 계약
- [IAcquirable](../02.%20UniEngine/02-Core/01-O.2-Interfaces/IAcquirable.md): 자신을 제어할 수 있는 단일 프록시 제공 객체 계약
- [IEnumerationSource](../02.%20UniEngine/02-Core/01-O.2-Interfaces/IEnumerationSource.md): 순회의 시작·이동·종료와 식별자를 제공하는 공통 계약
- [ValueEnumerator](../02.%20UniEngine/02-Core/01-O.3-Objects/ValueEnumerator.md): 순회 소스 계약을 사용하는 재사용 가능한 구조체 열거자

Core의 `01-O.2-Interfaces`에 순회 계약을 두고, 그 다음 `01-O.3-Objects`에 ValueEnumerator를 둔다. Objects는 Interfaces에 의존하며, AdaptiveCollection은 계약을 구현하고 구조체 열거자를 반환한다.

- [EventStream](../02.%20UniEngine/02-Core/02-E.3-EventStream/README.md): Rx 방식 이벤트 전파 시스템

- [Property](../02.%20UniEngine/02-Core/02-O.1-Property/Property.md): 외부 페이로드 저장 장치

- [Math.VectorFunctions](../02.%20UniEngine/02-Core/02-U.1-Utilities/Math/VectorFunctions.md)

### Level 3

- [EventHub](../02.%20UniEngine/02-Core/03-E.1-EventHub/README.md): 내부 EventStream으로 갱신 이벤트를 전달하며 객체별 연결과 생애주기를 관리하는 시스템
- [Utilities.TransformDataExtensions](../02.%20UniEngine/02-Core/03-U.1-Utilities/TransformDataExtensions.md)
- [Loco](../02.%20UniEngine/02-Core/03-U.1-Utilities/Loco.md): 매 틱 업데이트 제공

EventHub는 순서 그룹을 가진 EventStream을 소유하여 연결 수신자, 직접 Updated 구독자 순서로 갱신 이벤트를 전달한다. 구독·전파·갱신 수신자의 예외 격리는 스트림이 담당하고, 객체별 연결 정보와 Sleep·Awake·폐기 알림은 Hub가 관리한다.

## 3. UniEngine Surface

UniEngine Core를 기반으로 구성된 편의 기능 계층이다.
사용자가 자주 사용하는 기능을 더 쉽게 활용할 수 있도록 노출하거나 조합한 기능을 제공한다.

현재 범위는 [Surface 문서](../02.%20UniEngine/03-Surface/README.md)에 정리한다.

## 4. Services

UniEngine을 기반으로 구축된 서비스 프레임워크 계층이다.
각 서비스는 특정 문제 영역을 해결하기 위한 응용 프레임워크이며, UniEngine의 공통 기능을 조합하여 사용한다.

- [StateMachines.Usm](../02.%20UniEngine/04-Services/StateMachines/Usm.md): 상태 기계 (Unified State Machine, FSM + BT)
- [StateMachines.Scp](../02.%20UniEngine/04-Services/StateMachines/Scp.md): 클립 기반 재생기 (Sequence Clip Player, 페트리넷형 상태 기계)
- [MEP](../02.%20UniEngine/04-Services/MEP.md): Mesh 편집 패키지 (Mesh Extension Package)
- [GeoSystem](../02.%20UniEngine/04-Services/GeoSystem.md): 그래프 모델링 시스템
