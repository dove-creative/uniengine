# Hierarchy

## Dependency Direction

UniEngine의 계층은 역할과 의존 관계에 따라 구분한다.

각 계층은 상위 계층에 의존하며, 하위 계층은 상위 계층을 기반으로 구성된다.

0. Supportive Frameworks
1. Infrastructure
2. UniEngine Core
3. UniEngine Surface
4. Services

## 0. Supportive Frameworks

UniEngine과 그 하위 계층의 개발·검증·운영을 지원하는 외부 보조 프레임워크 계층이다.

- [Blackbox System](https://github.com/dove-creative/blackbox-system): 흐름 추적 장치
- [UniTest](https://github.com/dove-creative/unitest): 유닛 테스트 프레임워크

두 프레임워크는 독립 저장소에서 개발한다. Golden Hind 본체는 Blackbox System의 C# NuGet 패키지를 참조하며, UniTest 패키지는 테스트 프로젝트에서 사용할 수 있도록 준비되어 있다. 현재 Golden Hind 전용 테스트 프로젝트는 없으며, 실제 테스트를 추가할 때 UniTest 패키지를 연결한다. 두 패키지는 저장소의 `packages`에 보관하며, [패키지 문서](../../packages/README.md)에 버전·원본 커밋·SHA-256과 갱신 절차를 기록한다.

## 2. UniEngine Core

UniEngine의 기반 기능 계층이다.

객체 제어, 이벤트 전파, 데이터 표현, 공통 계약 등 하위 계층이 공통으로 의존하는 핵심 기능을 제공한다.

Event System의 구성과 공통 정책은 [Event System 개요](../02.%20UniEngine/EventSystem.md)를 따른다.

| Event System                                       | Objects                                    | Utilities                                                                                      |
| -------------------------------------------------- | ------------------------------------------ | ---------------------------------------------------------------------------------------------- |
|                                                    | Utilities<br>IInitializable<br>IAcquirable |                                                                                                |
| Handle/Token<br>AdaptiveCollections<br>EventStream | Property                                   | Math.VectorFunctions<br>Math.CompareValue<br>Utilities.DataComposer<br>Utilities.DataFormatter |
| EventHub                                           |                                            | Utilities.TransformDataExtensions<br>Loco                                                      |

### Level 1

- IInitializable: 초기화가 필요한 객체 계약
- IAcquirable: 자신을 제어할 수 있는 단일 프록시 제공 객체 계약

### Level 2

- Handle/Token: `Dispose` 시 저장된 이벤트를 발행하는 객체
- AdaptiveCollections: 순회 중 수정이 가능한 컬렉션
- EventStream: Rx 방식 이벤트 전파 시스템

- [Property](../02.%20UniEngine/Property.md): 외부 페이로드 저장 장치

- Math.VectorFunctions
- Math.CompareValue
- Utilities.DataComposer
- Utilities.DataFormatter

### Level 3

- EventHub: 생애주기에 연동되는 이벤트 전파 시스템
- Utilities.TransformDataExtensions
- Loco: 매 틱 업데이트 제공

### Top

- Kernel.Bootstrapper

## 3. UniEngine Surface

UniEngine Core를 기반으로 구성된 편의 기능 계층이다.
사용자가 자주 사용하는 기능을 더 쉽게 활용할 수 있도록 노출하거나 조합한 기능을 제공한다.

## 4. Services

UniEngine을 기반으로 구축된 서비스 프레임워크 계층이다.
각 서비스는 특정 문제 영역을 해결하기 위한 응용 프레임워크이며, UniEngine의 공통 기능을 조합하여 사용한다.

- StateMachines.Usm: 상태 기계 (Unified State Machine, FSM + BT)
- StateMachines.Scp: 클립 기반 재생기 (Sequence Clip Player, 페트리넷형 상태 기계)
- MEP: Mesh 편집 패키지 (Mesh Extension Package)
- GeoSystem: 그래프 모델링 시스템
