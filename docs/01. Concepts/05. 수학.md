# 수학

UniEngine의 수학 계산에서 사용하는 단위·허용 오차·실패 처리 기준이다.

## 목차

- 기본 단위
- 수학 도구와 의존 관계
- 근사 비교
- 예외와 비유한 값

## 기본 단위

각도와 각도 오차는 라디안으로 표현한다. 도 단위 입력·출력은 경계에서 명시적으로 변환하며 수학 API가 단위를 추측하지 않는다. 위치 오차는 해당 좌표와 같은 거리 단위를 사용한다.

## 수학 도구와 의존 관계

공통 타입의 네임스페이스는 Blackthunder.UniEngine.Mathematics이다. [Math 모듈](../02.%20UniEngine/01-Infrastructure/01-MT.1-Math/README.md)의 정적 UniMath가 비교·보정을 담당하고, [VectorFunctions](../02.%20UniEngine/01-Infrastructure/01-MT.2-VectorFunctions/README.md)가 매개변수에 따른 위치를 계산한다.

두 모듈은 Infrastructure에서 Configuration과 같은 레벨이며 서로 의존하지 않는다. 다음 레벨의 값 형식이 수학 도구를 사용하며 수학 도구는 Transform 등 엔진 값 형식이나 Core에 의존하지 않는다.

## 근사 비교

- 실수·벡터·자세의 비교에는 명시적인 근사 비교 API를 제공한다. 기본 수치·거리 오차는 UniMath.Epsilon, 기본 회전각 오차는 UniMath.AngularEpsilon을 사용한다. 호출자는 필요하면 허용 오차를 지정할 수 있다.
- Is는 허용 오차의 경계를 포함한다. 실수는 절대 차이, 벡터는 유클리드 거리로 판정하며 상대 오차는 자동 적용하지 않는다.
- Transform2D·Transform3D의 Is는 위치 오차와 회전각 오차를 별도 매개변수로 받는다. 2D 회전은 2π 주기의 최단 각도 차이를, 3D 회전은 정규화된 회전 차이를 비교한다. q와 -q는 같은 회전이다.
- Vector2Int·Vector3Int도 Is를 제공한다. 기본 Epsilon은 1보다 작으므로 기본 호출은 같은 정수 좌표만 일치하며, 더 큰 거리를 지정하면 근접 좌표를 판정할 수 있다. 비교 과정에서 정수 좌표를 float로 바꾸어 인접 좌표의 차이를 잃지 않는다.
- `Equals` · `==` · `GetHashCode`는 저장 성분의 정확한 값 동등성을 담당한다. 근사 일치는 추이성을 보장하지 않으므로 사전·집합의 키 동등성을 대체하지 않는다.
- 비교는 원본 값을 정규화하거나 보정하지 않는다. 부동소수점 계산의 반올림 차이는 허용 오차로 처리하며, 오차 0은 계산 결과의 정확한 일치를 요구한다.

## 예외와 비유한 값

- 의도한 처리 계약이 있는 경우를 제외하면 예외를 삼키지 않는다. 계산 실패를 숨기기 위해 catch 후 0·기본값·false를 반환하지 않고 호출자에게 전파한다.
- 허용 오차는 유한한 0 이상 값이어야 한다. 음수·NaN·무한대에는 ArgumentOutOfRangeException을 발생시킨다. 다른 비교 조건이 이미 거짓이어도 잘못된 오차와 정의할 수 없는 회전을 검사한다.
- 일반 실수·벡터 비교에서 비유한 피연산자를 거짓으로 판정하는 것은 명시된 비교 계약이다. 방향·회전 비교에서 영벡터·영쿼터니언 또는 비유한 방향·회전은 정의할 수 없는 입력이므로 예외를 발생시킨다.
- 예외, 거짓 반환, 비유한 결과의 전파를 각 API의 의도된 계약으로 구분하여 문서화한다. 예상되는 실패를 처리할 때도 호출자가 실패를 알 수 있는 결과를 제공한다.
