# Log System

진단 메시지의 전달·축적·파일 저장을 제공하는 모듈이다.

## 목차

- 소개
- 구성과 역할
- 대표 흐름
- 상세 문서

## 소개

| 항목 | 설명 |
| --- | --- |
| 개요 | 진단 메시지의 출력과 파일 기록이다. |
| 목적 | 실행 중 메시지를 바로 확인하면서 필요한 시점에는 모인 기록을 파일로 남길 수 있게 한다. |
| 구현 | 메시지 버퍼와 외부 출력기를 분리하고 Configuration이 제공한 경로에 기록을 저장한다. |

## 구성과 역할

Log는 버퍼·출력기·파일 저장을 관리한다. LogLevel은 메시지의 분류를 전달하며, Utilities는 컬렉션 등의 표시 형식을 만든다. 파일 저장 성공 후에만 버퍼를 비워 실패한 기록을 다시 시도할 수 있게 한다.

## 대표 흐름

1. Configuration과 Log를 초기화하여 데이터 경로와 출력기를 준비한다.
2. 메시지를 수준과 함께 버퍼에 기록하고 출력기로 전달한다.
3. Print가 버퍼를 저장한 뒤 내용과 저장 경로를 확정한다.
