# LogLevel

로그 메시지의 분류를 나타내는 열거형이다.

## 목차

1. 역할과 구성
2. 동작 흐름
3. 설계 기준
4. 구현 연결

## 역할과 구성

- 책임: 기록의 내용과 분류를 분리하여 같은 메시지 전달 경로에서도 출력기가 수준별 표시를 선택하게 한다.
- 보유 정보: Log·Warning·Error·Exception 네 분류를 정의한다. 별도의 가변 상태는 없다.

| 제공 서비스 | 제공 이유 |
| --- | --- |
| LogLevel 값 | Log와 출력기 사이에 메시지의 분류를 전달하는 공통 표현을 제공한다. |

## 동작 흐름

호출자가 수준을 선택하면 [Log](Log.md)가 메시지와 함께 버퍼에 기록하고 출력기에 전달한다. 출력기는 같은 수준을 사용하여 색상이나 표시 위치 같은 출력 방식을 선택할 수 있다.

## 설계 기준

- 수준 자체에 필터나 예외 발생 동작은 없다. Exception 분류의 기록도 예외를 던지는 요청을 뜻하지 않는다.
