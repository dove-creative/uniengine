# Exception Handler

예외의 최종 처리 방식을 애플리케이션에 연결하는 모듈이다.

## 목차

- 소개
- 구성과 역할
- 대표 흐름
- 상세 문서

## 소개

| 항목 | 설명 |
| --- | --- |
| 개요 | 애플리케이션 공통 예외 처리 경로이다. |
| 목적 | 이벤트 모듈이 최종 보고·중단 정책을 직접 결정하지 않고 애플리케이션의 처리 방침에 연결되게 한다. |
| 구현 | 등록된 처리기에 예외를 전달하며 처리기가 없으면 원래 예외를 재전파한다. |

## 구성과 역할

이벤트 소유자는 실패한 수신자 제거와 순회 복구를 책임진다. ExceptionHandler는 전달받은 예외의 최종 처리만 맡으므로 구독 정보나 이벤트 수명을 보관하지 않는다.

## 대표 흐름

1. 이벤트 소유자가 실패한 수신자를 정리한다.
2. Report가 애플리케이션 처리기에 예외를 전달한다.
3. 처리기가 정상 반환하면 호출자는 다음 작업을 계속하고, 예외가 나오면 현재 호출 경로로 전달한다.
