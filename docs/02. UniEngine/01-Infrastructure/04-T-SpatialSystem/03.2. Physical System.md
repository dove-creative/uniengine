# Physical System

PhysicalSpace는 미구현이며 후속 범위이다. 현재는 CollisionSpace의 생성·질의·알림·수명을 먼저 구현한다.

## 현재 상태

| 항목 | 상태 |
| --- | --- |
| PhysicalSpace2D·PhysicalSpace3D 및 Unity 래퍼 | 구현 코드와 빈 클래스 모두 두지 않음 |
| 공개 Rigidbody·IPhysicalComponent·물리 바인딩 | 제공하지 않음 |
| 중력·질량·속도·힘·토크 | 후속 구현 |
| Collider의 body 생성 인자·AttachedRigidbody | 제공하지 않음 |
| 물리 전용 테스트·사용 예시 | 현재 대상에서 제외 |

Unity가 접촉·Trigger를 발생시키는 데 필요한 내부 고정 강체는 CollisionSpace 연결 코드에 남긴다. 이는 공개 물리 기능이 아니며 공통 소비자가 생성하거나 관리하지 않는다.

## 후속 검토

PhysicalSpace를 구현할 때 CollisionSpace 상속, 공개 강체와 형상 연결, 독립 중력, 운동 방식과 수명 계약을 함께 검토한다. 당시의 충돌 공간 계약을 유지하는 방식으로 설계하며, 현재 문서는 확정된 공개 API를 정의하지 않는다.
