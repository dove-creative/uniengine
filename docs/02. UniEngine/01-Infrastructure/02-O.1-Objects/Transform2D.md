# Transform2D

2차원 위치와 회전을 함께 전달하는 가변 값 형식이다.

## 목차

- 역할과 구성
- 동작 흐름
- 설계 기준

## 역할과 구성

- 책임: 물체의 자세를 한 값으로 전달하면서 위치와 회전이 서로 다른 객체에 흩어지지 않게 한다.

보유 정보는 다음과 같다.

- Position: System.Numerics.Vector2로 표현한 위치이다.
- Rotation: 라디안 단위 float 회전값이다.
- Identity: 원점과 회전 0으로 구성된 기준 자세이다.

| 제공 서비스 | 제공 이유 |
| --- | --- |
| 생성자·성분 접근 | 위치와 회전을 함께 구성하고 갱신할 수 있게 한다. |
| 동등성·해시 | 전체 자세를 값으로 비교할 수 있게 한다. |
| ToString | 위치와 회전을 함께 표시하여 자세를 진단할 수 있게 한다. |

## 동작 흐름

호출자가 위치와 회전을 저장하고 소비자가 해당 값을 해석한다. [Transform2DJsonConverter](../03-M.1-Utilities/Json/Transform2DJsonConverter.md)는 Position 객체와 Rotation 숫자로 저장 표현을 구성한다.

## 설계 기준

- 각도 단위는 라디안이다. 도 단위 변환을 자동으로 수행하지 않는다.
- 배율이나 부모·자식 관계를 보유하지 않는다. 행렬 계산·좌표계 변환은 이 값을 사용하는 기능의 책임이다.
