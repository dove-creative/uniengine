# Vector3Int

3차원 정수 좌표를 값으로 전달하는 가변 구조체이다.

## 목차

1. 역할과 구성
2. 동작 흐름
3. 설계 기준

## 역할과 구성

- 책임: 정수 성분을 하나의 값으로 묶어 위치 정보의 전달과 비교에 같은 기준을 제공한다.

보유 정보는 다음과 같다.

- X·Y·Z: 읽고 쓸 수 있는 int 성분이다.
- Zero: 모든 성분이 0인 (0, 0, 0) 값을 제공한다.

| 제공 서비스 | 제공 이유 |
| --- | --- |
| 생성자·성분 접근 | 좌표를 구성하고 필요한 성분을 변경할 수 있게 한다. |
| Equals·비교 연산자·GetHashCode | 성분이 같은 좌표를 같은 값으로 비교하고 해시 기반 자료구조에서 사용하게 한다. |
| ToString | 문화권에 영향받지 않는 형태로 좌표를 표시하여 진단 정보를 읽기 쉽게 한다. |

## 동작 흐름

호출자가 성분으로 값을 구성하고 다른 객체에 복사하여 전달한다. 저장이 필요하면 [Vector3IntJsonConverter](../03-M.1-Utilities/Json/Vector3IntJsonConverter.md)가 동일한 성분을 JSON으로 변환한다. 값 형식은 좌표를 보관하고 변환기는 저장 표현을 담당한다.

## 설계 기준

- 좌표 성분이 달라지면 동등성과 해시도 달라진다. 해시 키로 사용하는 값은 저장한 키와 별개의 복사본이라는 점을 고려해야 한다.
- 산술 연산이나 좌표계 변환은 이 형식의 책임에 포함하지 않는다.
