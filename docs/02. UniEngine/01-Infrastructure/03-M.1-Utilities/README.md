# Utilities

값의 진단 표현과 직렬화를 제공하는 기반 도구 모음이다.

## 목차

- 소개
- 구성과 역할
- 대표 흐름
- 상세 문서

## 소개

| 항목 | 설명 |
| --- | --- |
| 개요 | 값의 표시와 저장 형식 변환이다. |
| 목적 | 같은 값을 출력하는 각 모듈이 표시·직렬화 규칙을 반복해서 구현하지 않게 한다. |
| 구현 | 사람이 읽는 진단 문자열과 기계가 읽는 JSON을 별도의 변환 기능으로 제공한다. |

## 구성과 역할

DataFormattingExtensions는 표시 문자열을 만들고 JSON 모듈은 형식별 성분의 읽기·쓰기를 담당한다. 이 모듈은 표현을 만들며, 출력 대상이나 파일 저장 수명은 소비자가 정한다.

## 대표 흐름

1. 호출자가 값과 필요한 표현 방식을 선택한다.
2. 표시 도구 또는 JSON 변환기가 입력을 해당 형식으로 변환한다.
3. Log나 호출자가 변환 결과를 출력·저장한다.
