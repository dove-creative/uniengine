# DataFormattingExtensions

값과 컬렉션을 사람이 읽기 쉬운 진단용 문자열로 바꾸는 정적 확장 기능이다.

## 목차

1. 역할과 구성
2. 동작 흐름
3. 설계 기준

## 역할과 구성

- 책임: 출력할 때마다 표현 규칙을 작성하는 일을 줄이고 로그와 진단 화면이 공통 형식을 사용하게 한다.
- 보유 정보: 지속 상태는 없다. 입력 값, 항목 선택 함수와 간단·상세 출력 옵션을 사용한다.

| 제공 서비스 | 제공 이유 |
| --- | --- |
| ToCompactString | 큰 숫자를 K·M 단위로 축약하여 짧은 공간에서 규모를 읽을 수 있게 한다. |
| 단일 값 ToDisplayString | 시간 길이·쿼터니언·Transform을 진단에 필요한 표현으로 바꾼다. |
| 컬렉션 ToDisplayString | 항목을 한 줄 목록 또는 개수·인덱스를 포함한 상세 표현으로 묶는다. |

## 동작 흐름

[Log](../03-M.3-LogSystem/Log.md)의 컬렉션 출력은 이 도구에 문자열 구성을 위임한다. 목록이 아닌 입력은 필요하면 목록으로 구체화한 뒤 각 항목을 선택·변환하고 한 문자열로 합친다.

## 설계 기준

- 숫자 표현에는 문화권 독립 형식을 사용한다. 선택 함수가 반환한 사용자 객체의 표현은 그 객체의 형식화 방식에 따른다.
- 시간 길이는 틱 정수 연산과 분·초 성분으로 계산하여 TimeSpan 전체 범위에서 단위 경계와 부호를 유지한다.
- 진단을 위한 표시 형식이며 역직렬화 계약이 아니다. 컬렉션 열거와 문자열 생성에는 할당이 발생할 수 있다.
