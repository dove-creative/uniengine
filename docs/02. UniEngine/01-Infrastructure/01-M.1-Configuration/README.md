# Configuration

애플리케이션의 설치 위치와 데이터 저장 위치를 확정하는 기반 모듈이다.

## 목차

- 소개
- 구성과 역할
- 대표 흐름
- 상세 문서

## 소개

| 항목 | 설명 |
| --- | --- |
| 개요 | 애플리케이션의 설치 경로와 공통 데이터 저장 위치이다. |
| 목적 | 모듈마다 경로를 따로 정하지 않고 같은 애플리케이션 데이터 영역을 사용하게 한다. |
| 구현 | 애플리케이션 식별자를 검증하여 경로를 한 번 확정하고, 이를 읽기 전용 속성으로 제공한다. |

## 구성과 역할

경로의 결정과 사용을 분리한다. Configuration이 InstallationPath와 DataPath를 함께 확정하고, 리소스 소비자와 Log 같은 모듈은 필요한 경로를 읽어 자신의 파일을 관리한다. 설치 디렉터리는 기존 위치를 사용하며 데이터 저장 디렉터리만 생성한다.

## 대표 흐름

1. 애플리케이션 식별자와 설치 디렉터리를 검사한다. 설치 경로를 생략하면 AppContext.BaseDirectory를 사용한다.
2. 사용자 문서 폴더 아래의 애플리케이션 전용 경로를 준비하고 설치 경로와 함께 확정한다.
3. 소비 모듈은 초기화된 경로를 읽어 자신의 작업을 수행한다.
