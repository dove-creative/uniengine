# Foundations

UniEngine의 실행 기능과 개발·검증·운영을 지원하며 별도 패키지로 제공하는 기반 프레임워크 계층이다.

## 목차

- 소개
- 연결 구조
- 상세 문서

## 소개

| 항목 | 설명 |
| --- | --- |
| 개요 | 실행 흐름 추적과 상태·동작 검증 등 공통 기반 기능을 다룬다. |
| 목적 | 본체와 테스트가 필요한 기반 기능을 독립된 패키지로 이용하게 한다. |
| 구현 | 본체와 테스트가 각각 필요한 외부 프레임워크의 컴파일된 패키지를 참조한다. |

## 연결 구조

Blackbox System은 본체에서 실행 흐름 추적을 지원한다. UniTest는 테스트 프로젝트에서 상태 전이를 구성하고 검증한다. 테스트는 본체를 참조하며 본체에 테스트 의존성을 추가하지 않는다.

프레임워크 자체의 객체 설계는 원본 저장소가 소유한다. UniEngine은 검증된 배포본을 소비하며 채택 버전과 출처는 패키지 문서에서 관리한다.
