# StateMachines

StateMachines는 호스트가 갱신할 때마다 작업을 진행하고, 그 결과로 다음에 실행할 작업을 결정하는 UniEngine 서비스이다.

## 목차

- 소개
- 실행 모델 선택
- 상세 문서

## 소개

| 항목 | 설명 |
| --- | --- |
| 개요 | USM은 노드 트리로 행동을 구성하고, Scp는 클립 사이의 재생 조건으로 연출을 구성한다. |
| 목적 | 개별 작업을 작성할 때 다음에 실행할 작업이나 전체 흐름까지 결정해야 하는 부담을 줄인다. |
| 구현 | USM에서는 부모의 전이기가 자식을 선택한다. Scp에서는 시퀀스가 클립의 종료 토큰을 모아 후속 클립을 시작한다. |

## 실행 모델 선택

| 필요한 동작 | 적합한 모델 | 호스트가 관찰하는 결과 |
| --- | --- | --- |
| 경비병이 순찰하다가 적을 발견하면 추적으로 전환한다. | USM. 한 부모 아래에서 상태를 바꾸거나 행동 트리의 우선순위로 현재 행동을 선점한다. | 어떤 노드가 실행 중인지, 이전 행동이 어떤 이유로 끝났는지 확인한다. |
| 문을 여는 연출에서 잠금이 풀리면 문과 효과음을 재생하고, 둘 다 끝나면 다음 연출을 시작한다. | Scp. 선행 클립 하나에 여러 후속 클립을 연결하고, 여러 종료 토큰을 하나의 재생 조건으로 묶는다. | 후속 클립은 조건에 맞은 토큰을 받고, 호스트는 시퀀스의 계속 진행 여부와 완료 여부를 받는다. |

두 모델은 독립적으로 사용할 수 있다. 특히 같은 이름의 Sequence가 맡는 범위가 다르다. Usm.Sequence는 **한 노드의 자식**을 순서대로 평가하는 전이기이다. Scp.Sequence는 **클립 재생 전체**를 시작·갱신·정지하는 객체이다. Scp는 기존 재생기를 이관한 초안이며, 토큰 소비와 중단 후 재시작은 후속 설계 범위이다.
