# Blackbox System

UniEngine에서 실행 흐름을 추적하기 위해 사용하는 외부 보조 프레임워크이다.

## 목차

- 소개
- 연결과 관리
- 참조

## 소개

| 항목 | 설명 |
| --- | --- |
| 개요 | 본체의 실행 과정을 관찰하는 흐름 추적 기능이다. |
| 목적 | 실행 중 발생한 활동을 추적하여 동작을 확인할 수 있게 한다. |
| 구현 | 본체가 BlackThunder.BlackboxSystem의 컴파일된 NuGet 패키지를 참조한다. |

## 연결과 관리

프레임워크 내부 구현은 독립 저장소가 소유하며 UniEngine 안에 원본 소스를 복제하지 않는다. 본체는 채택한 배포본을 참조하여 추적 기능을 사용한다.

현재 채택 버전은 0.2.0이다. 교체할 때는 소비 프로젝트에서 검증한 뒤 이전 버전을 제거하며, 버전·출처·검증 기록은 패키지 문서가 관리한다.
