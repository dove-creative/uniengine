# UniTest

Golden Hind에서 상태와 동작을 구성하여 재현·검증하는 외부 테스트 프레임워크이다.

## 목차

1. 소개
2. 연결과 관리
3. 참조

## 소개

| 항목 | 설명 |
| --- | --- |
| 개요 | 테스트 대상의 상태 전이와 기대 결과를 실행 가능한 검증으로 구성한다. |
| 목적 | 같은 조건과 동작을 재현하여 변경 이후에도 기대하는 결과가 유지되는지 확인한다. |
| 구현 | 테스트 프로젝트가 BlackThunder.UniTest의 컴파일된 NuGet 패키지를 참조한다. |

## 연결과 관리

프레임워크 내부 구현은 독립 저장소가 소유하며 Golden Hind 안에 원본 소스를 복제하지 않는다. 테스트만 UniTest를 참조하고 본체에는 테스트 의존성을 추가하지 않는다.

UniTest는 여러 단계에 걸친 상태 전이를 하나의 실행 흐름으로 재현할 때 사용한다. 어떤 모듈의 어떤 상태 전이를 검증할지는 각 모듈의 테스트 표와 계획이 정하고, 실행 결과는 실행 기록에 남긴다.

현재 채택 버전은 0.4.0이다. 교체할 때는 테스트 프로젝트에서 검증한 뒤 이전 버전을 제거하며, 버전·출처·지침 확인 이력은 패키지 문서가 관리한다.
