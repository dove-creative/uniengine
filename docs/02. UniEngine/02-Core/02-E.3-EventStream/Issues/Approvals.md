## 재검토 항목

### AP-01 ES-02 상태 단위

**현재 구현.** 같은 경로를 다시 구독하거나 나중에 구독해도 구독마다 상태를 처음부터 진행한다. 예를 들어 Take(2) 경로에 나중에 구독한 쪽도 값 두 개를 받는다.

**검토할 점.** 상태를 구독마다 둘지, 같은 연산자 호출로 만든 경로를 구독한 것끼리 공유할지 정한다. 공유하면 나중에 구독한 쪽은 남은 횟수를 이어받는다.

### AP-02 ES-03 종료 통지

**현재 구현.** 경로가 끝나면 종료 시점에 활성인 구독 모두에 완료를 통지한다. 예를 들어 Take(1).Branch()의 마지막 값을 처리하는 중에 Branch에 추가한 구독은 값을 받지 않고 완료만 받는다.

**검토할 점.** 같은 전파 중에 추가된 구독에도 완료를 통지할지 정한다.

### AP-07 ES-10 Merge

**현재 구현.** Merge는 외부 공급원만 입력으로 받는다. 같은 EventStream의 두 경로를 합치는 방법은 없다.

**검토할 점.** 경로를 합치는 기능이 필요한지, 필요하다면 그래프 안의 노드로 둘지 Branch를 Merge의 입력으로 받을지 정한다.

## 적용 기록

- AP-08: 다이어그램을 마지막 커밋과 같은 내용으로 되돌렸다.
- AP-09: zip을 저장소 밖으로 옮기고, 본 구현 보고서에서 zip을 가리키던 문장을 고쳤다.
- AP-10: EventSource의 전파 코드와, 기존 규칙을 고정하던 테스트 2개를 수정했다. 모듈 문서 반영과 전체 테스트 재실행은 남아 있다.
