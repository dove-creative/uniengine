# EventStream

EventStream은 공급원 하나와 구독 그래프를 소유한다. 같은 이벤트를 기다리는 구독자들이 조건을 한 번만 평가하도록 Where 경로를 합치고, 마지막 수신자가 떠나면 그 경로를 정리한다.

## 발행 권한

| 생성 방식 | 값을 보내는 곳 | 폐기할 때 |
| --- | --- | --- |
| 기본 생성자 | 스트림의 OnNext·OnCompleted·OnError | 내부 EventSource를 폐기한다. |
| 외부 IObservable을 전달한 생성자 | 외부 공급원 | 구독 연결만 해제한다. |
| EventStream.Merge | 여러 상위 EventSource 또는 결과 스트림에 대한 직접 발행 | 소유한 Merge 공급원과 상위 연결을 정리한다. |
| Branch | 부모의 경로에서 도달한 값 또는 분기에 대한 직접 발행 | 부모와의 연결 및 분기 공급원을 정리한다. |

소유한 공급원의 Enabled가 false이면 조건도 평가하지 않는다. 완료·오류는 계속 전달한다. 외부 공급원으로 만든 스트림에 직접 발행하거나 Enabled를 설정하면 InvalidOperationException이 발생한다.

## 전파와 변경

각 노드는 먼저 자신의 구독을 등록 순서대로 호출하고 자식을 방문한다. 전파 중 추가한 노드·구독은 다음 값부터 보인다. 구독 해제는 즉시 반영하므로 같은 값에서 차례를 기다리는 콜백도 건너뛴다. 완료와 오류는 조건과 관계없이 활성 구독을 순회한 뒤 폐기한다. 명시적 Dispose는 값을 보내거나 완료를 통지하지 않는다.

같은 스트림에 콜백 안에서 다시 값을 발행하면 InvalidOperationException이 발생한다. 콜백의 실패는 해당 구독만, 조건의 실패는 그 아래 경로를 해제한다. 실패를 ExceptionHandler.Report에 넘기며 보고가 예외를 던져도 나머지 구독을 계속 방문한다. 순회 후 첫 보고 예외를 발행자에게 전달한다. 기본 공급원은 이 때문에 그래프와의 연결을 끊지 않는다. 외부 Observable이 관찰자 예외를 잡거나 구독을 종료하는 방식은 그 공급원의 계약을 따른다.

## 구독과 연결의 수명

구독 핸들을 해제하면 더는 쓰지 않는 노드가 부모에서 제거된다. 루트 EventStream은 마지막 구독이 떠난 뒤에도 다시 구독할 수 있다. Branch는 첫 구독 시 부모와 연결되고 마지막 구독이 떠나면 스스로 폐기된다. Branch를 쓰는 예는 [경로 연결과 병합](EventStreamExtensions.md)에 있다.
