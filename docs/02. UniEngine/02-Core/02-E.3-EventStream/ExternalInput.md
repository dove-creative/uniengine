# 외부 입력

EventStream은 외부 `IObservable<T>`를 입력으로 받을 수 있다. 입력과 수신자의 계약은 표준 관찰자 인터페이스를 따른다.

| 계약 | 역할 |
| --- | --- |
| `IObservable<T>` | 스트림이 외부 입력에 요구하는 최소 계약이다. EventStream도 이 계약으로 다른 스트림의 입력이 될 수 있다. |
| `IObserver<T>` | 값·완료·오류 콜백을 하나의 수신자로 등록한다. |

## 사용 기준

외부 시스템이 값을 발행하면 그 Observable을 EventStream 생성자에 전달한다. 스트림을 폐기하면 외부 입력과의 연결만 해제하고, 외부 공급원 자체의 폐기는 그 소유자에게 맡긴다. 입력이 완료·오류로 끝나면 스트림도 같은 신호를 구독자에게 전달하고 폐기된다.

입력을 받는 스트림에도 OnNext로 값을 직접 넣을 수 있다. 값을 넣지 못하게 하려면 구독자에게 EventStream 대신 EventPath나 `IObservable<T>`를 넘긴다. EventPath에는 OnNext가 없다.

같은 수신자의 구독도 매번 별도 핸들이 생긴다. 기본 사용 예제는 [사용 예제](Usage.md)에 있다.
