# EventStream 순서 그룹

순서 그룹은 구독자가 값을 받는 단계를 나누는 경로 연산이다. ForOrder(order)에 열거형 값을 넘기면 그 그룹의 EventPath를 돌려준다. EventHub는 연결된 수신자를 첫 그룹, 직접 Updated 구독자를 다음 그룹에 두어 한 번의 갱신으로 두 그룹을 순회한다.

## 순서 지정

같은 위치의 그룹은 열거형 값이 작은 쪽부터 호출한다. 구독한 순서와 관계없고, 비었던 그룹이 다시 구독을 받아도 같은 자리로 돌아간다. 열거형 값은 int로 바꿔 비교하므로 int 범위를 벗어나는 값은 쓸 수 없다.

같은 그룹 안에서는 등록한 순서대로 구독자를 호출하고 Where 조건을 공유할 수 있다. 그룹 사이에는 조건을 공유하지 않는다. ForOrder는 Where처럼 경로 중간에서도 쓸 수 있고, 그 위치의 자식끼리만 순서를 정한다.

## 순서 없는 구독과 경로

- 순서 없는 구독자는 같은 위치의 모든 그룹보다 먼저 호출한다.
- 같은 위치의 그룹은 순서 값으로 자식을 관리하는 노드 하나에 모여 한 묶음으로 호출한다. 이 묶음과 순서 없는 Where, Debug, 새 스트림 연결 사이는 생성 순서를 따른다. 순서가 중요하면 모두 그룹 아래에 둔다.

한 전파가 모든 그룹을 포함한다. 앞 그룹에서 뒤 그룹에 구독을 추가하면 다음 전파부터 호출되고, 뒤 그룹의 핸들을 해제하면 현재 전파에서도 호출되지 않는다. 구체적인 등록 코드는 [사용 예제](Usage.md)에 있다.
