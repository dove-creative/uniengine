# EventStream 순서 그룹

`EventStream<T, TOrder>`는 구독자가 값을 받는 단계를 열거형으로 구분한다. EventHub는 연결된 수신자를 첫 그룹, 직접 Updated 구독자를 다음 그룹에 두어 한 번의 갱신으로 두 그룹을 순회한다.

## 순서 지정

생성자에 그룹 목록을 주면 그 순서를 따른다. 생략하면 열거형 값 순서를 사용한다. 같은 그룹은 처음 나타난 위치에 한 번만 등록된다. 미리 지정하지 않은 그룹은 ForOrder나 Subscribe에서 처음 사용할 때 뒤에 추가된다. 기본 구독과 경로 연산은 DefaultOrder에 속한다.

ForOrder(order)는 그 그룹 아래의 EventPath를 반환한다. 같은 그룹 안에서는 등록한 순서대로 구독자를 호출하고 Where 조건을 공유할 수 있다. 그룹 사이에는 조건을 공유하지 않는다. 비었던 그룹이 다시 구독을 받아도 처음 지정한 그룹 순서를 따른다.

한 전파가 모든 그룹을 포함한다. 앞 그룹에서 뒤 그룹에 구독을 추가하면 다음 전파부터 호출되고, 뒤 그룹의 핸들을 해제하면 현재 전파에서도 호출되지 않는다. 구체적인 등록 코드는 [사용 예제](Usage.md)에 있다.
