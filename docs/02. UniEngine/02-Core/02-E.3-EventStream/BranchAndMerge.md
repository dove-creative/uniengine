# Branch와 Merge

Branch와 Merge는 경로 끝이나 스트림에서 새 EventStream을 시작한다. 새 스트림은 자기 그래프를 가지며, 상위 그래프에는 연결 하나만 남는다.

## Branch

Branch는 값을 그대로 전달하는 새 EventStream을 만든다. 공유되는 Where 노드는 켜고 끌 수 없으므로, 그 지점 아래를 따로 다뤄야 할 때 Branch를 쓴다. 첫 구독까지 상위 쪽 노드를 만들지 않는다.

- 상위에서 오는 값은 앞선 필터를 통과해야 한다. Branch에 직접 넣은 값은 그 분기의 구독자에게만 전달된다.
- 같은 경로에서 두 번 호출하면 서로 다른 분기이다.
- Enabled는 그 분기에만 적용된다. Dispose는 그 분기 아래의 구독을 한 번에 해제한다.

마지막 구독을 해제하면 Branch와 상위의 연결이 정리된다. 상위가 완료·오류로 끝나면 연결된 Branch에도 같은 신호가 전달되고, 상위가 폐기되면 Branch는 통지 없이 폐기된다.

## Merge

Merge는 여러 스트림의 값을 하나의 새 EventStream으로 모은다. s2.Merge(s1)처럼 호출하며 호출한 스트림도 입력에 포함한다. 첫 구독 때 입력들과 연결된다.

- 입력 하나가 완료해도 나머지는 계속 값을 보낸다. 모든 입력이 완료하면 결과도 완료하고, 입력의 오류는 즉시 전달한다.
- 입력이 폐기되면 그 입력만 빠진다. 남은 입력이 모두 완료하면 결과도 완료하고, 입력이 하나도 남지 않으면 결과는 통지 없이 폐기된다.
- 입력은 EventStream이다. 경로를 합치려면 Branch로 스트림을 만들어 넘긴다. 외부 공급원은 EventStream 생성자로 감싸서 넘긴다.

Merge는 입력별로 값을 전달한다. 같은 값이 두 입력을 모두 통과하면 두 번 전달한다. 한 번만 전달하려면 두 조건을 합친 Filter 하나를 쓴다. 그래프 안에 부모가 여럿인 합류 노드는 두지 않는다.
