# EventRouter

기본 EventStream 하나를 감싸, 이벤트의 비트 마스크와 구독 마스크가 겹치는 수신자에게만 값을 전달하는 라우터이다.

## 역할과 구성

- 책임: 수신자가 관심 있는 이벤트 분류만 받도록 값을 받을 대상을 고른다.
- 감싼 스트림: 구독·연결·실패 처리·종료를 맡는 기본 EventStream이다. 라우터는 이 수명 관리를 모두 감싼 스트림에 맡긴다.
- 마스크 변환 함수: 이벤트 값을 uint 마스크로 바꾼다. 라우터를 만들 때 받는다.
- 현재 마스크: 전파 중인 값의 마스크이다. 대상을 지정한 구독은 이 값과 자신의 마스크를 비교한다.

라우터는 EventStream을 상속하지 않는다. 구현 형식은 공개하지 않으며, IEventRouter 계약과 EventRouterExtensions의 진입점으로만 다룬다.

| 제공 서비스 | 제공 이유 |
| --- | --- |
| IEventRouter | IEventStream 계약에 대상을 받는 Subscribe를 더한다. 대상 하나 또는 여러 개의 마스크를 구독에 묶는다. |
| EventRouterExtensions.Route(toMask) | 독립된 라우터를 만든다. 기본 EventStream처럼 종료 정책은 Complete이다. |
| source.Route(toMask) | 원본 뒤에 새 라우터를 연결한다. 연산자처럼 종료 정책은 NoSubscribers이다. |
| 대상을 받는 Chain·Connect | 라우팅 조건을 유지한 채 Observer를 경로에 연결한다. 확장 메서드로 제공한다. |
| OnNext | 값의 마스크를 한 번 계산한 뒤 감싼 스트림으로 전파한다. |

## 동작 흐름

1. 구독할 때 대상 값을 변환 함수로 마스크로 바꾼다. 대상이 여러 개이면 각 마스크를 OR로 합친다.
2. 대상을 지정한 콜백은 현재 마스크와 구독 마스크가 겹칠 때만 원래 콜백을 호출하도록 감싸 감싼 스트림에 등록한다.
3. OnNext가 들어온 값의 마스크를 계산하여 현재 마스크로 두고, 감싼 스트림에 값을 전파한다.
4. 대상을 지정한 구독은 두 마스크에 공통 비트가 하나라도 있는지 HasAny로 확인하고, 있으면 호출된다. 대상 없이 등록한 일반 구독은 항상 호출된다.
5. 구독 핸들은 감싼 스트림이 발급한다. 핸들을 해제하면 그 구독과 마스크 조건이 함께 사라진다.

예를 들어 [Flags] 열거형 Changes가 Health = 1, Mana = 2, Inventory = 4이고 변환 함수가 값을 그대로 uint로 바꾼다고 하자. Health와 Mana를 대상으로 한 구독의 마스크는 3이다.

| 들어온 값 | 마스크 | 마스크 3인 구독 |
| --- | --- | --- |
| Health | 1 | 받는다 |
| Inventory | 4 | 받지 않는다 |
| Health, Inventory | 5 | 받는다 |

OrderedEventStream이 실행 단계를 정하는 것과 달리, 라우터는 한 입력을 받을 수신자를 고른다. 연결·구독 수명과 전파 중 변경은 [모듈 개요](README.md)의 공통 규칙을 따른다.

## 설계 기준과 고려사항

라우팅은 수신자 목록을 도는 방식을 바꾸지 않는다. 각 구독이 값을 받을지 정하는 조건으로 표현할 수 있으므로, 라우터는 EventStream을 상속하지 않고 감싼다. 구독 수명·실패 처리·종료는 감싼 스트림의 규칙을 그대로 따르고, 라우터는 마스크 계산만 책임진다. 그래서 기본 EventStream에 라우팅 전용 확장 지점을 두지 않는다.

같은 값인지 비교하지 않고, 비트가 하나라도 겹치는지를 본다. 한 이벤트가 여러 분류에 동시에 속하는 경우를 하나의 마스크로 표현하기 위해서이다. 마스크의 의미는 변환 함수가 정하므로 라우터는 특정 이벤트 형식을 알지 못한다.

- 마스크는 전파마다 한 번만 계산한다. 대상을 지정한 구독이 늘어나도 변환 함수 호출 횟수는 늘지 않는다.
- 멀티캐스트 콜백도 항목마다 마스크를 확인한다. 앞 항목이 구독을 해제하면 뒤 항목을 호출하지 않는 기본 규칙이 그대로 유지된다.
- 콜백 안에서 같은 라우터에 다시 값을 발행하면 그 호출은 기본 EventStream 규칙대로 그 콜백의 실패로 처리된다. 바깥 전파의 남은 구독은 바깥 값의 마스크로 계속 판정한다.
- 변환 함수가 없으면 모든 값의 마스크가 uint.MaxValue가 되어, 빈 대상 목록으로 등록한 구독을 제외하면 모든 값을 받는다.
- 대상 목록이 비어 있으면 구독 마스크가 0이 되어 어떤 값도 받지 않는다. 마스크가 0인 이벤트도 대상을 지정한 구독에는 전달되지 않는다.
- 대상을 지정하지 않은 Subscribe·Chain·Connect는 감싼 스트림의 일반 구독 경로를 사용한다. 이 구독에는 마스크 조건이 없으므로 같은 전파 순회에서 모든 값을 받는다.
- 완료·오류 통지는 마스크와 관계없이 모든 구독에 전달한다.
- 변환 함수를 실행하는 도중 라우터가 폐기되면 그 값은 전달하지 않는다.
- IEventRouter의 With는 IEventStream을 반환한다. 라우터 형식을 유지한 채 종료 정책을 바꾸려면 TerminationMode를 직접 설정한다.
