# ILifecycleAndEventHubBuilder

연결된 수신자의 알림을 단계적으로 설정하는 구성 계약 묶음이다.

## 목차

- 역할과 구성
- 동작 흐름
- 설계 기준과 고려사항

## 역할과 구성

- 책임: 허브의 내부 저장 구조를 드러내지 않고 연결 하나의 반응을 구성하게 한다.
- 상태 계약: 구성 대상의 저장 방식은 구현체가 소유한다.

| 제공 서비스 | 제공 이유 |
| --- | --- |
| ILifecycleHubBuilder | 폐기 완료 반응만 필요한 연결에 최소 구성 기능을 제공한다. |
| IEventHubBuilder | object 갱신·필터·폐기 알림을 구성한다. |
| IEventHubBuilder&lt;TEventArgs&gt; | 형식 있는 갱신 구성과 상위 계약의 변환 경로를 제공한다. |

## 동작 흐름

Connect의 반환 계약에서 콜백을 등록하고 같은 구성기를 반환받아 이어서 설정한다. 제네릭 기본 구현은 비제네릭 입력을 검사하고 대리자를 변환하여 전달한다.

## 설계 기준과 고려사항

구성 계약은 설정 대상의 저장 방식과 분리하며, 같은 구성기를 반환하여 관련 콜백을 한 연결에 누적하도록 한다.

- 구성 계약은 연결 해제 핸들이 아니다.
- 연결 제거는 허브의 Disconnect로 요청한다.
- LifecycleHub와 EventHub의 중복 설정 방식은 각각의 구현 설명을 따른다.
