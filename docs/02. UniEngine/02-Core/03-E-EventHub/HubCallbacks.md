# HubCallbacks

허브의 직접 생애주기 구독을 개별 항목으로 관리하고 격리 실행하는 내부 객체이다.

1. 역할과 구성
2. 동작 흐름
3. 설계 기준과 고려사항
4. 구현 연결

## 역할과 구성

- 책임: 허브의 직접 생애주기 구독에 대한 스냅샷 순회와 개별 실패 처리를 담당한다.
- 보유 정보: 콜백·원래 대리자·변환 여부·활성 상태를 가진 Subscription 목록을 보관한다.

| 제공 서비스 | 제공 이유 |
| --- | --- |
| Add·Remove | 멀티캐스트를 개별 구독 항목으로 관리하고 해제 항목을 비활성화한다. |
| Snapshot·Invoke | 실행 순서를 고정하면서 이미 해제한 항목은 현재 스냅샷에서도 제외한다. |
| Clear | 허브 정리 시 모든 항목과 보유 대리자 참조를 비운다. |

## 동작 흐름

멀티캐스트를 개별 항목으로 등록하고 스냅샷으로 실행 순서를 고정한다. 해제된 항목은 비활성화하여 기존 스냅샷에서도 건너뛴다. 실패 항목은 제거하고 ExceptionHandler에 보고한다.

## 설계 기준과 고려사항

스냅샷과 별도의 활성 상태를 함께 두어 목록의 구조를 고정해 순회하면서도 구독 해제를 즉시 반영한다. 허브 내부 보조 책임이므로 공용 컬렉션 API와 분리한다.

- 현재 갱신 전파는 OrderedEventStream이 담당하며 이 내부 도구는 허브의 직접 폐기 알림 등에 사용한다.
- 스냅샷 배열 할당이 있고 공용 재사용 API로 노출하지 않는다.
