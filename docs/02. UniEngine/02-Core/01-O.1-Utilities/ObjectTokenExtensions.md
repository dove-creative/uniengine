# ObjectTokenExtensions

참조형 토큰이 null이 아니면서 같은 객체인지 확인하는 정적 확장 기능이다.

## 목차

- 역할과 구성
- 협력 흐름과 기준

## 역할과 구성

- 사용 정보: 비교할 두 참조이며 별도의 상태를 보관하지 않는다.
- 제공 서비스: IsValidAndSameTokenWith는 null을 배제한 참조 동일성 검사로 작업에 저장한 토큰과 현재 토큰을 비교한다.

## 협력 흐름과 기준

호출자가 이전에 보관한 참조와 현재 참조를 전달하면 첫 참조의 null 여부를 확인한 뒤 두 참조를 비교한다. 객체 내부의 값이나 폐기 상태를 읽지 않으므로 여러 종류의 참조형 작업 토큰에 적용할 수 있다.

여기서 유효함은 null이 아니라는 뜻이다. Token의 IsDisposed와 값 동등성은 검사하지 않는다.
