## 소개

| 항목 | 설명 |
| --- | --- |
| 개요 | 객체 코드의 비트 연산과 참조 비교이다. |
| 목적 | 반복되는 비트 판정과 토큰 동일성 검사를 일관된 작은 기능으로 제공한다. |
| 구현 | 별도 수명이나 저장 상태가 없는 정적 확장 함수로 표현한다. |

## 구성과 역할

FlagExtensions는 비트 집합을 다루고 ObjectTokenExtensions는 참조형 토큰의 동일성을 확인한다. 각 함수는 전달된 값만 판단하며 이벤트 구독이나 토큰의 폐기 상태를 관리하지 않는다.

## 대표 흐름

1. 호출자가 비트 값 또는 비교할 참조를 전달한다.
2. 도구가 결합·포함 여부 또는 참조 동일성 결과를 반환한다.
3. 이벤트 마스크를 검사하는 Filter 같은 소비자가 결과를 자신의 전파·제어 정책에 사용한다.
