# FlagExtensions

int·uint·ulong 비트 집합의 포함 여부와 결합, enum의 비트 변환을 제공하는 정적 확장 기능이다.

## 목차

- 역할과 구성
- 동작 흐름
- 설계 기준과 고려사항

## 역할과 구성

- 책임: 비트 연산의 의미를 호출부에서 드러내어 포함 조건을 같은 기준으로 판단한다.
- 사용 정보: 지속 상태 없이 전달된 비트 값과 목록을 사용한다.

| 제공 서비스 | 제공 이유 |
| --- | --- |
| HasAny·HasAll | 한 비트라도 겹치는 조건과 모든 비트를 포함하는 조건을 구분하여 검사한다. |
| Combine | 여러 비트 값을 하나로 합쳐 공통 판정에 사용할 수 있게 한다. |
| ToBits | enum의 기반 형식 크기만큼 비트를 보존하고 ulong으로 넓혀 공통 비트 표현을 만든다. |

## 동작 흐름

호출자가 비트 집합과 검사할 값을 전달하면 포함 여부나 결합 결과를 바로 반환한다.

enum을 비트로 사용할 때는 ToBits로 ulong 표현을 얻은 뒤 포함 여부를 검사하거나 다른 비트와 결합한다. ToBits는 기반 형식의 1·2·4·8바이트를 그대로 읽고, 남는 상위 비트를 0으로 채운다.

## 설계 기준과 고려사항

비트 집합의 해석을 작은 순수 연산으로 분리하여 호출부가 정수 연산식을 반복하지 않게 한다.

- 숫자의 동등성 비교가 아니라 비트 연산이다.
- int·uint·ulong에 같은 의미의 HasAny·HasAll과 두 값·배열·열거 목록의 Combine을 제공한다. 기존 int·uint 사용은 유지된다.
- 빈 목록의 결합 결과는 0이며, HasAll의 검사 마스크가 0이면 true이다.
- flags enum을 비트로 다룰 때는 ulong으로 대응한다. enum 선언의 기반 형식은 강제하지 않는다.
- enum을 ulong으로 바꿀 때는 캐스트 대신 ToBits를 사용한다. int 기반 enum의 31번 비트를 ulong으로 직접 캐스트하면 부호가 확장되어 상위 32비트가 모두 켜질 수 있다. ToBits는 같은 값을 `0x80000000`으로 보존한다.
- ToBits는 부호 있는 기반 형식을 숫자로 변환하지 않으며 박싱하지 않는다. sbyte의 −128은 `0x80`, uint의 31번 비트는 `0x80000000`, ulong의 63번 비트는 `0x8000000000000000`으로 보존된다.
- ToBits는 일반 enum 변환 함수이므로 `[Flags]` 특성을 요구하지 않는다. `[Flags]`와 0이 아닌 마스크를 요구하는 ForFlags의 검사는 경로 연산에서 담당한다.
