# FlagExtensions

int·uint 비트 집합의 포함 여부와 결합을 제공하는 정적 확장 기능이다.

## 목차

1. 역할과 구성
2. 동작 흐름
3. 설계 기준과 고려사항

## 역할과 구성

- 책임: 마스크 연산의 의미를 호출부에서 드러내어 이벤트 분류와 포함 조건을 같은 기준으로 판단한다.
- 사용 정보: 지속 상태 없이 전달된 비트 값과 목록을 사용한다.

| 제공 서비스 | 제공 이유 |
| --- | --- |
| HasAny·HasAll | 한 비트라도 겹치는 조건과 모든 비트를 포함하는 조건을 구분하여 검사한다. |
| Combine | 여러 분류 값을 하나의 마스크로 합쳐 공통 판정에 사용할 수 있게 한다. |

## 동작 흐름

EventRouter 등이 이벤트와 구독 대상의 마스크를 구성하고 교집합 존재 여부로 전파 대상을 고른다.

## 설계 기준과 고려사항

비트 집합의 해석을 작은 순수 연산으로 분리하여 라우터가 정수 연산식을 반복하지 않게 한다.

- 숫자의 동등성 비교가 아니라 비트 연산이다.
- 빈 목록의 결합 결과는 0이며, HasAll의 검사 마스크가 0이면 true이다.
