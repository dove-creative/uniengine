# Handle과 Token

해제할 동작을 객체로 묶고 폐기에 연결하는 모듈이다.

## 목차

1. 소개
2. 구성과 역할
3. 대표 흐름
4. 상세 문서

## 소개

| 항목 | 설명 |
| --- | --- |
| 개요 | 폐기에 연결한 정리 동작이다. |
| 목적 | 연결을 사용한 쪽이 제공자의 내부 해제 절차를 알지 않고 연결 수명을 끝낼 수 있게 한다. |
| 구현 | 정리 동작을 객체에 담아 반환하고 폐기 시 한 번 실행한다. |

## 구성과 역할

Handle은 생성 시 정리 동작을 받아 실행 권한을 전달한다. Token은 같은 수명에 묶을 동작을 나중에도 추가·제거할 수 있다. 둘 다 연결 대상 자체보다 해제 동작과 실행 상태를 소유한다.

## 대표 흐름

1. 제공자가 연결을 만들고 그 연결의 정리 동작을 Handle에 담는다.
2. 소비자는 반환 객체를 자신의 사용 수명 동안 보관한다.
3. 소비자가 폐기하면 저장된 동작이 실행되어 연결을 해제한다.
