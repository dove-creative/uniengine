# ILifecycleSubject

생애주기 허브를 제공하는 도메인 객체의 계약이다.

## 목차

- 역할과 구성
- 동작 흐름
- 설계 기준과 고려사항

## 역할과 구성

- 책임: 도메인 객체의 폐기 계약·상태·관찰용 허브를 함께 제공한다.
- 상태 계약: IDisposable을 확장하고 IsDisposed와 ILifecycleHub 형식의 LifecycleHub를 노출한다.
- 제공 이유: 수신자가 구체 도메인 형식에 의존하지 않고 객체의 종료를 관찰하게 한다.

## 동작 흐름

도메인 객체가 허브를 소유하고 수신자가 LifecycleHub를 통해 연결한다. 객체의 Dispose 구현이 자신의 상태와 허브 정리를 조율한다.

## 설계 기준과 고려사항

허브와 허브를 소유하는 객체는 별개 계약이다. 인터페이스 구현만으로 허브 생성이나 자동 폐기가 이루어지지 않으며, 객체와 허브의 상태 일치는 구현체의 책임이다.

[IEventSubject](../03-E.2-EventHub/IEventSubject.md)는 이 계약을 확장하여 이벤트 허브를 생애주기 관찰 경로로도 제공한다.
