# ILifecycleHub

수신자가 객체의 생애주기에 연결하고 폐기 상태를 관찰하는 계약이다.

## 목차

- 역할과 구성
- 동작 흐름
- 설계 기준과 고려사항

## 역할과 구성

- 책임: 수신자에게 연결·해제와 상태 조회를 제공한다.
- 상태 계약: 구현체의 IsDisposed를 노출하며 자체 상태는 보관하지 않는다.

| 제공 서비스 | 제공 이유 |
| --- | --- |
| IsDisposed | 소유 허브의 폐기 완료 상태를 확인한다. |
| Connect | 수신자를 식별자로 받아 완료 반응을 구성할 Builder를 제공한다. |
| Disconnect | 더 이상 필요하지 않은 수신자 연결을 제거한다. |

## 동작 흐름

수신자는 Connect가 반환한 ILifecycleHubBuilder에 폐기 완료 반응을 등록한다. 관찰을 중단할 때는 같은 수신자 식별자로 Disconnect를 호출한다.

## 설계 기준과 고려사항

소비자 계약에는 Dispose를 포함하지 않아 허브 소유자의 폐기 책임과 관찰자의 역할을 구분한다. 구체 형식의 폐기 진입점은 별도로 존재한다.

[IEventHub](../03-E.2-EventHub/IEventHub.md)는 이 계약을 확장한다. 연결 등록 시점과 폐기 중 해제 정책은 각 구현의 설명을 따른다.
