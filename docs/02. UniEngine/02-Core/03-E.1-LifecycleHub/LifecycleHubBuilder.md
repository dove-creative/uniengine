# LifecycleHubBuilder

LifecycleHub의 수신자 하나에 폐기 완료 반응을 등록하는 구성 객체이다.

## 목차

- 역할과 구성
- 동작 흐름
- 설계 기준과 고려사항

## 역할과 구성

- 책임: 수신자 식별자와 폐기 완료 콜백을 소유 허브에 연결한다.
- 보유 정보: 소유 LifecycleHub와 수신자 식별자를 보관한다.
- 제공 서비스: ILifecycleHubBuilder.OnDisposed로 완료 반응을 등록하고 같은 Builder를 반환한다.

## 동작 흐름

Connect는 수신자에 대응하는 Builder를 준비하고, OnDisposed 호출이 수신자를 식별자로 하여 Action 등록을 확정한다. 직접 이벤트 구독도 같은 사전을 사용하며 대리자 자체를 식별자로 삼는다. 소유 허브가 폐기되면 등록 경로 구분 없이 콜백을 통지한다.

## 설계 기준과 고려사항

한 식별자의 완료 반응은 한 번 등록하며 직접 구독과의 키 충돌도 중복 등록으로 거부한다. 멀티캐스트 콜백은 결합된 Action 그대로 보관한다. null 콜백은 허용하며 통지할 때 건너뛴다. 폐기 중이거나 완료된 허브에는 새 반응을 등록할 수 없다.

Builder는 갱신·필터·수면 상태를 갖지 않는다. 연결 제거는 소유 허브의 Disconnect로 요청한다.
