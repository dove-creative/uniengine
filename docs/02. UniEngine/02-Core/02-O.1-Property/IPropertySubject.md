# IPropertySubject

외부 페이로드 저장소를 가진 객체임을 나타내는 계약이다.

## 목차

1. 역할과 구성
2. 협력 흐름과 기준

## 역할과 구성

- 책임: 외부 기능이 도메인 객체의 구체 형식과 독립적으로 저장소에 접근하게 한다.
- 노출 정보: Property 형식의 읽기 전용 속성이다.
- 제공 서비스: 공통 저장소 접근점을 제공하여 외부 데이터마다 도메인 계약을 추가하지 않게 한다.

## 협력 흐름과 기준

구현체가 Property를 제공하면 외부 기능이 자신의 키와 데이터를 등록·조회·제거한다. 이 계약은 저장소 접근만 규정하며 저장소 생성, 페이로드 소유권과 자동 정리는 구현체와 소비자가 조율한다.
