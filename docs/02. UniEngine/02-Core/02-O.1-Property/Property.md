# Property

도메인 객체의 필드를 늘리지 않고 외부 페이로드를 키별로 보관하는 저장 객체이다.

4. 구현 연결

## 역할과 구성

- 책임: 외부 기능의 데이터를 키로 구분하여 보관하고 도메인 객체의 필드 확장을 줄인다.
- 보유 정보: object 키와 object 값의 사전, Count와 HasValue를 제공한다.

| 제공 서비스 | 제공 이유 |
| --- | --- |
| Add·인덱서 | 중복 등록을 거부하는 추가와 기존 값 교체를 구분한다. |
| Get·TryGet | 필요한 값의 존재 여부와 요청 형식을 확인하며 페이로드를 읽는다. |
| GetAndRemove·Remove·Clear | 한 번 소비할 값의 회수와 더 이상 필요 없는 참조의 제거를 제공한다. |
| Count·HasValue·IDictionary 계약 | 저장 상태를 관찰하고 표준 사전 소비 코드와 연결한다. |

## 동작 흐름

외부 기능이 키와 값을 저장하고 필요한 시점에 형식을 지정해 조회한다. 한 번 사용할 값은 GetAndRemove로 회수한다.

## 설계 기준과 고려사항

키별 저장과 형식 지정 조회를 결합하여 다양한 외부 데이터를 담되 형식 불일치를 호출부에 드러낸다. 저장소의 참조 관리와 페이로드 자체의 생애주기는 분리한다.

- TryGet&lt;T&gt;는 키가 없을 때 false이며 저장 형식이 다르면 InvalidCastException이다.
- null을 수용하는 T에는 null 값을 반환할 수 있다.
- Remove·Clear는 참조를 제거할 뿐 저장 값의 Dispose를 호출하지 않는다.
