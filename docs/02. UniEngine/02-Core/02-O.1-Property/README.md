# Property

도메인 객체에 외부 페이로드 저장소를 제공하는 모듈이다.

## 목차

1. 소개
2. 구성과 역할
3. 대표 흐름
4. 상세 문서

## 소개

| 항목 | 설명 |
| --- | --- |
| 개요 | 도메인 객체의 외부 페이로드 저장소이다. |
| 목적 | 외부 기능이 필요로 하는 데이터를 도메인 객체의 필드마다 추가하지 않고 보관할 수 있게 한다. |
| 구현 | 키 기반 저장소와 이를 노출하는 계약을 분리한다. |

## 구성과 역할

Property는 값 등록·조회·제거를 맡고 IPropertySubject는 저장소를 제공하는 객체의 접점이다. 외부 기능은 자신의 키를 사용하여 데이터의 의미와 수명을 관리한다.

## 대표 흐름

1. 도메인 객체가 저장소를 소유하고 계약으로 노출한다.
2. 외부 기능이 키를 정해 데이터를 등록하고 필요할 때 조회한다.
3. 데이터를 회수하거나 제거하여 저장소와의 연결을 정리한다.
