# DataFormatter

Core Level 2의 Utilities 하위에 배치된 데이터 형식화 설계 항목이다.

## 목차

- 정의된 범위
- 설계 상태

## 정의된 범위

계층표는 이름과 위치를 지정한다. 입력·출력 형식과 변환 정책은 아직 정의되지 않았다. Infrastructure의 DataFormattingExtensions와의 관계도 별도 설계가 필요하다.

## 설계 상태

현재 src에 대응 구현이 없는 설계 항목이다. 객체의 보유 상태·서비스·협력 흐름은 후속 설계에서 정할 범위이다.
