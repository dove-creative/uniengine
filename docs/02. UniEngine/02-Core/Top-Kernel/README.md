## 목차

2. 정의된 범위

## 소개

- 개요: Kernel의 Bootstrapper를 다루는 설계 영역이다.
- 목적: Core의 Top에서 부트스트랩 책임을 배치하기 위한 분류이다.
- 구현 상태: 현재 src에 대응 구현이 없으며 각 항목에서 정의된 역할과 미정 범위를 구분한다.
