# IEnumerationSource

값 열거자가 사용할 순회의 시작·이동·종료를 제공하는 공통 계약이다.

## 목차

- 역할과 구성
- 동작 흐름
- 설계 기준과 고려사항

## 역할과 구성

- 책임: 저장 자료구조의 순회 정책을 공통 열거자의 수명 제어와 분리한다.
- 상태 계약: 구현체가 순회 위치와 유효한 long 식별자를 소유한다. 계약은 구체적인 저장 자료구조를 요구하지 않는다.

| 제공 서비스 | 제공 이유 |
| --- | --- |
| BeginEnumeration | 각 순회를 식별하여 오래된 열거자와 새 순회를 구분한다. |
| TryMoveNext | 열거자가 저장 구조를 몰라도 유효한 순회의 다음 값을 요청할 수 있게 한다. |
| EndEnumeration | 정상 종료·조기 종료·실패가 같은 정리 경로를 사용하게 한다. |

## 동작 흐름

ValueEnumerator가 첫 이동에서 시작을 요청하고 같은 식별자로 이동한다. 끝에 도달하거나 폐기될 때 소스가 대기 변경과 순회 상태를 정리한다.

## 설계 기준과 고려사항

순회 상태는 소스가 소유하고 호출 수명은 열거자가 제어한다. 이 분리로 컬렉션마다 다른 변경 반영 정책을 같은 열거자에 연결할 수 있다.

- 실패한 시작은 기존 순회를 훼손하지 않아야 한다.
- false 이동 뒤에도 종료가 필요하다.
- 중복·오래된 종료는 무시하고, 종료된 순회의 이동은 거부한다.
- 오래된 열거자가 남을 수 있는 동안 식별자를 재사용하지 않는다.
