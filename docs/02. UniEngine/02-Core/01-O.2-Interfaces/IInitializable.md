# IInitializable

초기화 진입점을 공통으로 노출하는 계약이다.

## 목차

1. 역할과 구성
2. 협력 흐름과 기준
3. 구현 연결

## 역할과 구성

- 책임: 구체 형식과 관계없이 객체의 준비 작업을 요청할 수 있게 한다.
- 보유 정보: 인터페이스 자체는 상태를 보관하지 않는다.
- 제공 서비스: Initialize는 호출자가 구현체별 준비 절차를 알지 못해도 초기화를 요청할 진입점이다.

## 협력 흐름과 기준

초기화를 조율하는 객체가 이 계약을 통해 준비를 요청하고 실제 작업은 구현체가 수행한다. 계약은 준비 작업의 존재만 규정하며 초기화 횟수 제한·완료 상태·실패 복구 정책은 구현체가 결정한다.
