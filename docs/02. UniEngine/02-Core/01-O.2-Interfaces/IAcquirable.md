# IAcquirable

객체를 제어할 수 있는 단일 프록시의 획득 상태와 획득 경로를 노출하는 계약이다.

## 목차

- 역할과 구성
- 동작 흐름
- 설계 기준과 고려사항

## 역할과 구성

- 책임: 제어 프록시를 획득하는 호출부와 구체적인 획득·해제 구현을 분리한다.
- 상태 계약: IsAcquired로 획득 상태를 제공한다. 핸들 형식은 IDisposable을 구현해야 한다.

| 제공 서비스 | 제공 이유 |
| --- | --- |
| IsAcquired | 소비자가 현재 획득 상태를 관찰할 수 있게 한다. |
| Acquire·TryAcquire | 핸들을 요구하는 경로와 성공 여부를 확인하며 시도하는 경로를 제공한다. |

## 동작 흐름

소비자가 제어 핸들을 획득하여 사용한 뒤 폐기하는 생애주기를 구현체와 연결한다.

## 설계 기준과 고려사항

핸들에 IDisposable을 요구하여 제어권 사용의 끝을 폐기 동작에 연결할 수 있게 한다. 계약 자체가 제어권이나 동시 접근 상태를 저장하지는 않는다.

- AlreadyAcquiredException은 중복 획득을 표현하는 InvalidOperationException 파생 형식이다.
- 실제 획득·해제와 동시 접근 정책은 이 인터페이스 안에 구현되어 있지 않다.
