# Interfaces

상위 객체 기능을 구체적인 구현과 분리하는 공통 계약 모음이다.

## 목차

1. 소개
2. 구성과 역할
3. 대표 흐름
4. 상세 문서

## 소개

| 항목 | 설명 |
| --- | --- |
| 개요 | 초기화·제어 획득·순회 수명에 대한 공통 계약이다. |
| 목적 | 소비자가 구체 객체의 저장 방식이나 구현 형식에 의존하지 않고 필요한 기능을 요청하게 한다. |
| 구현 | 수명 단계별 요청과 필요한 상태를 인터페이스로 정의하고 실제 정책은 구현체에 둔다. |

## 구성과 역할

IInitializable은 준비 진입점, IAcquirable은 제어 핸들의 획득, IEnumerationSource는 순회 세션의 시작·이동·종료를 정의한다. 서로 다른 책임의 계약이므로 모든 객체가 이들을 함께 구현할 필요는 없다.

## 대표 흐름

1. 구현체가 자신의 책임에 해당하는 계약을 구현한다.
2. 소비자는 계약을 통해 요청하고 반환값·상태를 받는다.
3. 구현체는 자신의 저장 구조와 수명 규칙에 맞춰 요청을 처리한다.
