## 소개

| --- | --- |
| 개요 | 공통 계약 위에서 동작하는 재사용 객체이다. |
| 목적 | 열거자가 구체 컬렉션의 저장·변경 정책을 알지 않아도 순회 수명을 제어하게 한다. |
| 구현 | ValueEnumerator가 순회 소스 계약을 참조하고 자신의 현재 값과 시작·종료 상태만 보관한다. |

## 구성과 역할

ValueEnumerator는 소비자와 IEnumerationSource 사이의 수명 제어를 맡는다. 소스는 위치·유효한 식별자·변경 반영을 소유한다. 이 분리로 AdaptiveCollection 외의 참조형 소스에도 같은 열거자를 사용할 수 있다.

## 대표 흐름

1. 소비자가 열거자 값을 받으며 이때는 소스 순회를 시작하지 않는다.
2. 첫 이동부터 공통 계약으로 값을 요청한다.
3. 끝·조기 종료·예외에서 종료 계약을 호출하여 소스가 자신의 상태를 정리하게 한다.
