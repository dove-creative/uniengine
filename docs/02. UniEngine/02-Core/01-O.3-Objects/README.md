## 소개

| 항목 | 설명 |
| --- | --- |
| 개요 | 공통 계약 위에서 동작하는 재사용 객체이다. |
| 목적 | 구체 컬렉션과 독립적으로 순회 수명을 관리한다. |
| 구현 | ValueEnumerator는 순회 계약을 호출하여 순회를 시작하고 진행하거나 종료한다. |

## 구성과 역할

ValueEnumerator는 소비자와 IEnumerationSource 사이의 수명 제어를 맡는다. 소스는 위치·유효한 식별자·변경 반영을 소유한다. 이 분리로 AdaptiveCollection 외의 참조형 소스에도 같은 열거자를 사용할 수 있다.

## 대표 흐름

1. 소비자가 받은 열거자의 첫 이동에서 순회가 시작된다.
2. 끝·조기 종료·예외에서는 종료 계약을 호출하여 소스가 자신의 상태를 정리하게 한다.
