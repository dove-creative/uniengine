# ValueEnumerator

IEnumerationSource의 순회 수명을 제어하는 재사용 가능한 구조체 열거자이다.

## 목차

- 역할과 구성
- 동작 흐름
- 설계 기준과 고려사항

## 역할과 구성

- 책임: 저장 구조를 참조하지 않고 값 열거와 순회 정리의 수명을 연결한다.
- 보유 정보: 소스 참조, 순회 식별자, 마지막 반환 값과 시작·종료 상태를 보관한다. 컬렉션의 인덱스나 추가 대기 목록은 보관하지 않는다.

| 제공 서비스 | 제공 이유 |
| --- | --- |
| MoveNext·Current | 공통 소스에서 다음 값을 받아 표준 열거 패턴에 제공한다. |
| Dispose | 끝까지 방문하지 않은 경우에도 소스의 정리 계약을 실행할 수 있게 한다. |
| Reset | 재시작을 지원하지 않음을 명시하여 종료된 순회 식별자의 재사용을 막는다. |

## 동작 흐름

생성은 소스에 접근하지 않는다. 첫 MoveNext에서 시작하고 이후 값을 받아 Current를 갱신한다. 끝·이동 예외·Dispose에서 종료 계약을 호출한다. 시작 실패는 다른 순회를 종료하지 않는다.

## 설계 기준과 고려사항

첫 이동까지 시작을 늦추어 열거자를 생성한 것만으로 컬렉션을 순회 중 상태로 만들지 않는다. 구조체로 반환하여 직접 순회의 열거자 할당을 없애고, 식별자를 통해 복사본이 오래된 순회를 조작하는 문제를 소스에서 판별하게 한다.

- 기본값 구조체는 빈 열거자이며 시작 전 Dispose도 소스를 시작하지 않는다.
- 생성자에 명시적으로 null 소스를 전달하면 ArgumentNullException이다.
- Current는 시작 전 기본값, 이후 마지막 반환값이다.
- 시작한 복사본은 같은 소스 순회를 공유한다.
- 인터페이스 반환은 박싱하며, 참조형 소스를 사용하는 직접 foreach 경로에는 열거자용 힙 할당이 없다.
- 값 형식 소스를 IEnumerationSource로 변환해 전달하면 소스 참조를 만들 때 박싱될 수 있다.
- 종료 계약에서 예외가 발생하면 호출자에게 전달된다. 이동 예외를 처리하는 중 종료도 실패하면 정리 예외가 이동 예외를 대체할 수 있으므로 소스는 정리 실패 여부와 관계없이 활성 상태를 복구해야 한다.
