# UniEngine Surface

Core의 기능을 사용하기 쉬운 형태로 노출하거나 조합하는 편의 기능 계층이다.

## 목차

- 소개
- 설계 범위

## 소개

- 개요: Core를 이용하는 반복적인 구성과 사용 흐름을 묶는 계층이다.
- 목적: 사용자가 기반 객체의 조합을 매번 직접 구성하지 않고 필요한 기능에 접근하게 한다.
- 구현 방향: Core의 공개 기능을 조합하여 편의 기능을 제공한다.

## 설계 범위

Hierarchy에 계층의 목적이 정의되어 있으며 현재 src에 대응 구현이나 개별 객체 목록은 없다. 제공할 편의 기능이 정해지면 그 객체의 책임과 구성 흐름을 문서화한다.
